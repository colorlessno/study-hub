# テーマカタログ

このファイルは、リポジトリ内の番号付き163テーマを再発見するための公開索引です。テーマ名を検索し、リンク先の要件または学習ノートから開始してください。学習方法と到達度は [学習再開ガイド](./LEARNING_GUIDE.md) を参照します。

## 目的別の入口

- Web開発を基礎から学ぶ: `web01` → `web04` → `web07` → `web13` → `web16` → `web20` → `web26`
- APIとDBを学ぶ: `base10` → `web13` → `db02` → `web16` → `web35` → `web42`
- セキュリティを学ぶ: `security01` → `security02` → `security03` → `security05` → `security06` → `security17`
- テストと運用を学ぶ: `devops02` → `devops03` → `devops04` → `devops06` → `devops07` → `devops09`
- GitとPR中心のチーム開発を学ぶ: `base06` → `base07` → `base08` → `devops01` → `devops02`
- AIシステムを学ぶ: `system17` → `system18` → `system22` → `system03` → `system31` → `system36` → `system44`
- 開発工程を説明できるようにする: `base01` → `base03` → `base04` → `arch01` → `arch02` → `base11`

## カタログの扱い

- テーマ追加時は、要件・学習ノート・実装のいずれかへ到達できるリンクを追加します。
- 「正規ルート」が別テーマにある重複項目は、削除せず統合先を明示し、機械可読カタログでは`aliasOf`として管理します。
- 到達度や学習日はこのカタログに混ぜず、[学習ログ](./LEARNING_LOG_TEMPLATE.md)で管理します。
- 分野単位の種別と検証契約は[機械可読カタログ](./catalog/fields.json)で管理します。
