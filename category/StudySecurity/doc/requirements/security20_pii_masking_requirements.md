# security20 PIIマスキング 要件定義

## 1. 目的

ログやAI入力・出力に個人情報を出しすぎないため、PII検出とマスキングの基本を学ぶ。

## 2. 学習対象

- PII
- masking
- redaction
- log sanitization
- AI input privacy

## 3. 作成する成果物

- PIIマスキングサンプル
- 検出ルール例
- ログ出力比較
- AI入力前処理メモ

## 4. 機能要件

| ID | 要件 |
|---|---|
| FR-01 | メールアドレスや電話番号を検出できる |
| FR-02 | 検出したPIIをマスキングできる |
| FR-03 | ログにはマスキング後の値だけを出力し、dummy元値が残らないことを確認できる |
| FR-04 | AI入力前にPIIを伏せる方針を説明できる |

## 5. 非機能要件

| ID | 要件 |
|---|---|
| NFR-01 | 実個人情報をサンプルに使わない |
| NFR-02 | 正規表現だけでは限界があると明記する |
| NFR-03 | マスキングしすぎによる業務影響も説明する |

## 6. 対象外

- 個人情報保護法の法的判断
- DLP本格導入
- 高度な固有表現抽出

## 7. 受入条件

- PIIの例を説明できる
- dummy PIIが種別labelへ変わり、元値が出力されないことを確認できる
- ログやAI入力にPIIを出すリスクを説明できる

## 8. 学習観点

- ログは便利だが漏洩源にもなる
- AI入力にも個人情報保護が必要
- 検出ルールには限界がある
