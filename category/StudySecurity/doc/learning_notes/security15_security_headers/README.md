# security15 セキュリティヘッダー

ブラウザの動作を制限する応答ヘッダーがある場合と、ない場合を比較します。

## このテーマで確認すること

- CSPで読み込み元と画面埋め込みを制限する
- `X-Frame-Options`で画面埋め込みを拒否する
- `X-Content-Type-Options`でMIME形式の推測を抑止する
- 参照元情報とブラウザ機能の送信・利用範囲を制限する
- ローカルHTTPではHSTSを確認対象にしない

## 最初に取り組むこと

1. StudyHubの「起動」を押す。
2. 「防御ヘッダーあり」を実行し、応答ヘッダーを確認する。
3. 「比較用: 防御ヘッダーなし」を実行し、2つの応答を比較する。
4. 「防御ヘッダーの設定処理」を表示し、画面に返った値と照合する。
5. 「各ヘッダーの役割と適用方針」を表示し、各設定が制限するブラウザ動作を確認する。

## 防御ヘッダーありで確認する値

| ヘッダー | この教材の設定 |
|---|---|
| `Content-Security-Policy` | 自サイト以外の読み込み、画面埋め込み、objectを拒否 |
| `X-Frame-Options` | 画面埋め込みを拒否 |
| `X-Content-Type-Options` | MIME形式の推測を抑止 |
| `Referrer-Policy` | 別の接続元へ送る参照元情報を制限 |
| `Permissions-Policy` | 位置情報、カメラ、マイクを無効化 |
| `Cache-Control` | 教材の応答を保存しない |

## 教材の範囲

ヘッダーは入力検証、出力時の無害化、認証、権限確認の代わりにはなりません。HSTSはHTTPSで運用する設定のため、このローカルHTTP教材では付与していません。
