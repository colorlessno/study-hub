# security18 検索文書の安全な利用

信頼済み、信頼できない、利用制限付きの架空文書を検索し、検索結果と利用可否を分けて確認する教材です。外部LLMとベクトルデータベースは使用しません。

## このテーマでできるようになること

- 3つの信頼区分と利用方法を画面で比較できる
- 検索結果に含まれることと、回答へ利用できることが別であると確認できる
- 文書内の命令を実行せず、信頼区分と権限で扱いを決める処理を確認できる

## 最初に取り組むこと

1. StudyHubで教材を起動する。
2. 「全件」を選び、「検索する」を押す。
3. 信頼済み、信頼できない、利用制限付きの検索例を一つずつ確認する。
4. 「信頼区分ごとの検索処理」と「検索に使う文書例」を表示し、結果と実装を照合する。
5. 確認後に教材を停止する。

## 信頼区分と利用方法

| trust | action | 扱い |
|---|---|---|
| `trusted` | `cite_with_label` | 出典を付けて回答材料にする |
| `untrusted` | `ignore_instructions_and_review_content` | 文書内の命令を無視し、内容を別途確認する |
| `restricted` | `needs_approval` | 利用前に権限または承認を確認する |

## 実装で確認すること

- 検索順位が高くても、文書の信頼度が高いとは限らない
- 信頼できない文書は、本文中の命令と情報としての内容を分けて扱う
- 利用制限付き文書は、回答生成後に隠すのではなく検索前の権限確認で除外する
- 出典IDだけでは内容の正しさを保証できない
- 実運用では文書の版、所有者、更新日時、利用判断も記録する

## 学習用実装の範囲

- 単純な部分一致だけを使い、ベクトル検索と順位付けは行わない
- 架空文書だけを使用する
- 回答生成と文書単位の権限管理は行わない
