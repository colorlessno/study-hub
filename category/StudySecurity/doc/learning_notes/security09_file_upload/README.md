# security09 ファイルアップロード制御

ファイル名とサイズを入力し、受け付けてよい入力と拒否すべき入力を画面で比較するテーマです。実際のファイルは送信せず、アップロード処理の入口にある検証を確認します。

## このテーマでできるようになること

- 許可する拡張子とサイズ上限による判定を確認できる
- 拡張子とサイズを拒否する理由を結果から区別できる
- 画面側の検証だけではファイル内容の安全性を保証できないことを確認できる

## 最初に取り組むこと

1. StudyHubで教材を起動する。
2. 「許可されるCSV」を選び、「入力を検証」を押す。
3. 確認例を順に切り替え、拡張子・サイズ・判定理由の違いを見る。
4. 「拡張子とサイズの検証処理」を開き、画面の結果と条件分岐を対応させる。
5. 「アップロード全体の防御方針」を開き、受信後に必要なMIME・内容・保存名・保存場所の検査を確認する。

## 画面で確認すること

| 確認例 | ファイル名 | サイズ | 期待結果 |
|---|---|---:|---|
| 許可されるCSV | `sample.csv` | 1000 | 許可 |
| 許可されない拡張子 | `sample.exe` | 1000 | `extension_not_allowed` |
| サイズ上限を超えるPDF | `sample.pdf` | 1048577 | `size_exceeded` |
| 負のサイズ | `sample.txt` | -1 | `invalid_size` |
| 大文字の拡張子 | `REPORT.PDF` | 4096 | 小文字へ変換して許可 |

## 実装を確認する

- 許可対象は`.csv`、`.txt`、`.pdf`
- サイズは0バイト以上1MiB以下
- 拡張子は小文字へ変換して比較する
- 判定結果には入力値、拡張子、許可状態、拒否理由を表示する

この教材が検査するのはファイル名とサイズだけです。MIME形式、ファイル内容、マルウェア、保存先は検査していません。本番ではサーバー側にも同じ制限を置き、内容検査と保存領域の分離を追加します。
