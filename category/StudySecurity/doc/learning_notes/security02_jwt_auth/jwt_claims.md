# JWT Claim

| claim | この教材での値 | 受信側の確認 |
|---|---|---|
| `sub` | `u-demo` | 誰のtokenかを識別する。実在ユーザーとの照合は本教材の対象外 |
| `role` | `operator` | 認可判断に利用できる属性。security03ではサーバー側の権限表と組み合わせる |
| `iat` | 発行時刻 | 発行時刻が不自然でないか確認する材料になる |
| `exp` | 通常は発行10分後 | 現在時刻を超えたtokenを拒否する |

JWTは署名で改ざんを検出できますが、暗号化ではありません。秘密情報をpayloadに入れません。

本番では用途に応じて`iss`、`aud`、`jti`等も検討します。claimを増やすだけで安全になるわけではなく、発行者と受信者が各値の意味と検証規則を合意する必要があります。
