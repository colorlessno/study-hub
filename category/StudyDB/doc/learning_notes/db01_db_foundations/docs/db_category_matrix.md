# DBの種類を比較する

| 種類 | データの持ち方 | 得意な読み取り | 主な更新方法 | 後続テーマ |
|---|---|---|---|---|
| RDB | 表と表同士の関係 | SQL、表の結合、条件検索 | 複数データを一つの取引として更新 | db02〜db06 |
| 文書型DB（Document DB） | JSONに近い文書 | 文書単位の取得 | 関連するデータを一つの文書として更新 | db07 |
| キー・バリュー型DB（Key-Value DB） | キーと値の組 | キーを指定した高速取得 | 値の置換、有効期限付きの一時保存 | db07 |
| キャッシュ | 元データの一時的な複製 | よく使う値の高速取得 | 正本から再作成、期限切れで削除 | db07 |
| 全文検索用DB | 検索用の索引 | 単語検索、絞り込み、検索順位 | 正本の変更を索引へ反映 | db07 |
| DWH | 集計に適した列中心の表 | 大量の履歴集計 | 追加や一括取り込み | db07 |
| Vector DB | 数値の並びで表した特徴 | 意味が近いデータの検索 | 特徴量の再計算と索引更新 | db07 |

## OLTPとOLAP

- OLTPは、注文登録や在庫更新のように、日々の登録・更新を正確に処理します。RDBがよく使われます。
- OLAPは、月別売上や傾向分析のように、大量の履歴をまとめて読み取ります。DWHがよく使われます。

一つのシステムでOLTPとOLAPの両方が必要な場合、業務用RDBを正本にし、分析用DWHへ必要なデータを複製する構成があります。
