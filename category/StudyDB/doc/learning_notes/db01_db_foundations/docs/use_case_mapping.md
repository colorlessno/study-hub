# 用途ごとの選定例

| 用途 | 選ぶ保存先 | データの位置付け | 理由 | 障害時の復元元 |
|---|---|---|---|---|
| 注文登録 | RDB | 正本 | 顧客、注文、在庫の整合性を守る必要がある | RDBのバックアップと更新履歴 |
| ログイン状態 | キー・バリュー型DBまたはキャッシュ | 一時データ | キーによる高速取得と有効期限が重要 | 再ログインまたはRDBの利用者情報 |
| 商品全文検索 | 全文検索用DB | 派生データ | 単語、表記揺れ、検索順位を扱う | 商品RDBから索引を再作成 |
| 月次売上分析 | DWH | 派生データ | 大量の履歴を集計する | 注文RDBや保管済みの履歴から再取り込み |
| FAQのAI検索 | Vector DBと文書の正本 | 派生データと正本 | 意味が近い文書の候補取得と、回答根拠の原文保管を分ける | 原文から特徴量と索引を再作成 |

## 用語

- 正本: システムが正しい値として扱う保存先
- 派生データ: 正本から作り直せる検索用・分析用のデータ
- 一時データ: 期限切れや再作成を前提にしたデータ
