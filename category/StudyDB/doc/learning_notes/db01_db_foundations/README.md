# db01 DB基礎と保存方式の選び方

ファイル、Excel、オブジェクトストレージ、RDB、NoSQL、キャッシュ、全文検索、DWH、Vector DBを比較し、用途に合う保存先を理由付きで選びます。

## このテーマでできるようになること

- 保存するデータと利用方法から、候補となる保存方式を絞り込める
- 正本、派生データ、一時データを区別できる
- 用途に合わない保存方式と、採用しない理由を説明できる

## 最初に取り組むこと

1. 「保存方式を比較する」を開き、ファイル、Excel、オブジェクトストレージ、RDBの違いを確認する
2. 「DBの種類を比較する」を開き、各方式が答えやすい問いを確認する
3. 「用途ごとの選定例」を開き、正本、派生データ、一時データの違いを確認する
4. 「選定結果を記入する」を開き、注文履歴、商品画像、商品名の全文検索に適した保存先と理由を書く
5. 同じひな形に、自分が扱ったシステムのデータと復元元を書く

## 選ぶときの観点

- 複数人や複数処理から更新要求があり、順番と整合性を管理する必要があるか
- データ同士の整合性を守る必要があるか
- 主キー検索、条件検索、全文検索、集計、類似検索のどれを行うか
- データを正本として保持するか、正本から作り直せるか、短時間だけ保持するか
- 障害時にどの保存先から復元するか

## このテーマで使用するもの

StudyHubの教材欄で、比較資料、用途ごとの選定例、選定結果の記入ひな形を切り替えて使用します。Docker、外部DB、外部サービスは使用しません。
