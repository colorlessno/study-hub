# db07 NoSQL・キャッシュ・検索・DWH比較

同じ顧客・注文データを複数の保存形式で比較し、用途に応じて保存先を選ぶ考え方を確認するテーマです。

## このテーマでできるようになること

- RDB、キー・値、文書形式の構造と問い合わせ方の違いを説明できる
- 正本、検索用の派生データ、キャッシュを区別できる
- 商品検索と売上集計で求められるデータ構造の違いを説明できる
- ベクトルDBとRAGを、原文や業務DBの代わりではなく検索支援として説明できる

## 最初に取り組むこと

1. 「RDB形式の例」「キー・値形式の例」「文書形式の例」を順に開く。
2. 顧客名を変更するときに、各形式で修正する箇所を数える。
3. 「データストア比較」を開き、最新注文表示、商品検索、月次売上集計に向く保存先を選ぶ。
4. 「キャッシュ・検索・DWHの役割」を開き、正本から作り直せるデータを確認する。
5. 「ベクトルDBとRAG」と「RAG向けデータの例」を開き、検索結果から元文書へ戻るための情報を確認する。
6. 「選定判断の記録ひな形」を開き、任意の作業フォルダーへ別名で保存して、各用途の正本・派生先・選定理由・注意点を記入する。

## 比較するときの観点

- どの問い合わせを速くしたいか
- 1件の更新で何か所を書き換えるか
- 更新の遅れを許容できるか
- 障害時にどの正本から作り直すか
- 履歴を残すのか、現在値だけを保持するのか

このテーマでは外部のNoSQLサービスを起動しません。画面内の資料とサンプルデータを比較し、自分で使い分けを判断します。StudyHubはひな形の閲覧と所在表示を行い、記入内容はブラウザー内へ保存しません。
