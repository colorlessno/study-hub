# db04 トランザクション・ロック・分離レベル

データの確定と取り消し、更新時に取得されるロック、現在の分離レベルをPostgreSQLで順番に確認するテーマです。

## このテーマでできるようになること

- COMMITで残る変更とROLLBACKで取り消される変更を区別できる
- 更新処理が保持するロックを確認できる
- ROLLBACKでロックと変更が取り消されることを説明できる
- 分離レベルがトランザクション内で読み取れるデータを決めることを説明できる

## 最初に取り組むこと

1. Docker Desktopが起動していることを確認し、画面の「起動」を押す。
2. 「テーブルと初期データを準備」を選んで実行する。
3. 「確定と取り消しを比較」を実行し、商品1と商品2の在庫を比較する。
4. 「単一セッションのロック状態を確認」を実行し、更新中のロックとROLLBACK後の在庫を確認する。
5. 「分離レベルと現在値を確認」を実行し、表示された分離レベルと在庫を確認する。
6. 「トランザクション記録」と「ロック観察記録」を任意の作業フォルダーへ別名保存し、実際の結果を記入する。
7. 確認後に「停止」を押す。

## 実行結果の見方

- 確定後は商品1の在庫が10から8へ変わる
- 取り消し後は商品2の在庫が100のまま残る
- 更新直後は現在のセッションが保持するロックが表示される
- ROLLBACKした後は、商品1の在庫が実行前の値へ戻る

「確定と取り消しのSQL」「ロックを確認するSQL」「最終状態を確認するSQL」を開くと、画面で実行した処理の境界をソースで確認できます。
