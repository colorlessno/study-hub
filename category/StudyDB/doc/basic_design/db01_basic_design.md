# db01 基本設計

## 画面の役割

db01は、保存方式を比較し、選定理由を記入する文書テーマです。実行環境の起動やAPI操作は行いません。StudyHubの教材欄から比較資料と記入ひな形を切り替えて使用します。

## 画面の構成

| 部分 | 内容 |
|---|---|
| テーマの説明 | 保存方式を選ぶ目的と進め方を示す |
| 学習項目 | READMEの確認内容を一項目ずつ記録する |
| 教材 | 比較資料、選定例、記入ひな形、設計文書を切り替える |
| 前後のテーマ | StudyDB内の前後のテーマへ移動する |

起動、停止、状態更新、API実行、コマンド実行の操作は表示しません。

## 学習の流れ

1. 保存方式の比較で、ファイル、Excel、オブジェクトストレージ、RDBを比較する
2. DBの種類を比較し、得意な読み取り方法と更新方法を確認する
3. 用途ごとの選定例で、正本、派生データ、一時データを確認する
4. 記入ひな形に指定された3つの用途を整理する
5. 自分が扱ったシステムを一つ追加する
6. 採用しない候補と理由を記入する

## 教材の構成

| 教材 | 役割 |
|---|---|
| README | 学習の進め方 |
| 保存方式の比較 | DB以外を含む保存方式の比較 |
| DBの種類 | DBごとのデータの持ち方と得意な処理 |
| 用途ごとの選定例 | 正本、派生データ、一時データを含む記入例 |
| 選定結果の記入ひな形 | 学習者が選定理由を整理する作業対象 |
| 要件定義・基本設計・詳細設計 | 画面と教材を作った理由の確認 |

## 記入内容

指定された3つの用途と、自分が扱ったシステムを分けて記入します。各行に保存先、データの位置付け、理由、採用しない候補、復元元を残します。

## 確認観点

- READMEの順番と教材欄の表示が一致するか
- 技術用語が日本語の説明だけでも理解できるか
- 一つのチェック項目に複数の作業を詰め込んでいないか
- 記入ひな形だけで選定理由と復元元を整理できるか
