# db03 基本設計
## 正規化とERモデリング

## 0. 関連要件

- `../requirements/db03_normalization_er_modeling_requirements.md`

## 1. 設計目的

非正規な注文表からエンティティを抽出し、正規化とER表によって更新不整合を減らす過程を追える教材にする。

## 2. 対象範囲

- 業務文からの名詞抽出
- 第1正規形、第2正規形、第3正規形
- 1対多、多対多、中間テーブル
- ER図またはテキストER表
- 逆正規化が必要になる条件

## 4. 入力

| 入力 | 内容 |
|---|---|
| 非正規表 | 顧客、注文、商品、明細が混在した表 |
| 業務ルール | 顧客は複数注文でき、注文は複数商品を持つ |
| 変更例 | 顧客名変更、商品価格変更、注文キャンセル |

## 5. 出力

| 出力 | 内容 |
|---|---|
| 正規化手順 | 非正規表から3NF相当までの分割理由 |
| ER表 | entity、attribute、relation、cardinality |
| 不整合メモ | 正規化前に起こる重複と更新漏れ |
| 設計結果記録 | 分割理由、ER表、逆正規化の判断を記録するひな形 |

## 6. 処理方針

1. 非正規表の重複と更新不整合を確認する
2. 繰り返し項目を分離する
3. 主キーに完全従属しない項目を分離する
4. 推移従属する項目を分離する
5. 多対多を中間テーブルで表現する
6. 逆正規化が許容される条件を整理する

## 7. 確認観点

- 非正規表の問題点を説明できるか
- テーブル分割の理由を更新不整合と結びつけて説明できるか
- 多対多を中間テーブルで表現できるか
