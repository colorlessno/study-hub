# desktop01 Electronによるローカル環境構築の自動化

## このテーマでできるようになること

- Electronアプリの画面・公開処理・メイン処理の役割を説明できる
- 画面側から任意のコマンドを実行できない仕組みを説明できる
- 処理の開始から終了までに記録する内容を確認できる
- 失敗時の後片付けを安全な範囲に限定する方法を確認できる

## 目的

デスクトップアプリからローカル環境構築を実行するときに、画面へ任意のコマンドを実行する権限を渡さない設計を学ぶ。この教材では安全な模擬処理を使い、画面とメイン処理の境界、実行内容の選択、進捗記録、後片付け、失敗時の処理を確認する。

## 最初に取り組むこと

1. StudyHubの「起動」を押し、Electronアプリを開く。
2. アプリで計画表示の処理を選び、実行結果がアプリの作業フォルダ内に限定されることを確認する。
3. 画面の「画面とメイン処理の連携」を開き、画面側・公開処理・メイン処理の役割を確認する。
4. 「実行を許可する処理」と「許可処理一覧のソース」を開き、処理IDから実行内容を選ぶ流れを確認する。
5. 「処理状態の変化」と「実行記録の例」を開き、開始から終了までに記録する内容を確認する。
6. 「失敗時の後片付け」と「後片付けのソース」を開き、操作できるフォルダの範囲を確認する。
7. 「安全性テストのソース」を開き、安全のために自動確認している内容を整理する。

## コマンドで確認する場合

```cmd
cd category/StudyDesktop\src\apps\desktop01_electron_local_environment_automation
rtk npm.cmd run verify
```

- Electron画面を使わなくても、許可処理、模擬処理の書き込み先、後片付けの範囲、処理状態の変化をテストできる。
- Electronアプリを直接起動する場合は `rtk npm.cmd run start` を実行する。
- 失敗時は「アプリの操作説明」にある復旧手順を確認し、アプリの作業フォルダ外を操作しない。
