# 知識マップ × システム 対応表

## 見方

- **知識マップ → システム**：各知識項目がどのSystemで体験できるか
- **システム → 知識マップ**：各Systemがどの知識項目を体験できるか
- 現在のロードマップは **16システム構成** を前提とする

### スコープ外（今後の課題）

| 項目 | 理由 |
|------|------|
| ファインチューニング・LoRA | コスト・専門性が高く別テーマとして扱う |
| 機械学習（物体検知・画像分類） | AIシステム開発とは別の専門領域 |
