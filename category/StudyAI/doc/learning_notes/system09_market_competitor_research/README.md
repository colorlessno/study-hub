# system09 市場競合調査エージェント

公開情報を使って複数の調査対象を比較し、根拠付きのレポートとして保存・再表示するテーマです。

## このテーマでできるようになること

- 調査種別、目的、対象、重点項目、自社情報、調査の詳しさを条件として指定できる
- 企業別の調査結果、比較表、SWOT分析、動向、出典、調査の限界を確認できる
- 保存済みレポートを条件で絞り込み、詳細を再表示できる
- 作成したレポートをMarkdownファイルとして出力できる

## 最初に取り組むこと

1. 「教材用の入力例を使う」を押し、設定された調査条件を確認する。
2. 「調査開始」を押し、公開情報の収集とレポート作成が完了するまで待つ。
3. 調査条件、要約、企業別の結果、比較表、SWOT分析、出典、調査の限界を確認する。
4. 「Markdown出力」を押し、保存されたレポートをファイルとして確認する。
5. 「レポート閲覧画面」で条件を指定して絞り込み、保存済みレポートの詳細を開く。

## 画面で確認すること

- 必須の調査目的と対象が未入力の場合は調査を開始できない
- 調査対象は1行1件で最大5件まで指定できる
- 調査結果に入力した条件、検索回数、企業別の内容、比較結果、出典が表示される
- 調査種別、調査対象、日付で保存済みレポートを絞り込める
- 一覧から開いたレポートとMarkdown出力の内容が一致する

## 処理のつながり

`System09Page.tsx` が調査条件をAPIへ送り、`router.py` が調査サービスを呼び出します。調査グラフは計画作成、検索語生成、公開情報の収集、情報源評価、レポート作成、保存を順に実行します。AIの応答が制限時間内に完了しない場合は、収集済みの出典を確認できる暫定レポートを保存します。

## うまく動かないとき

- Docker Desktopが起動しているか確認する。
- 調査目的と対象の両方が入力されているか確認する。
- 外部サイトを取得できない場合は、時間を置いて再実行する。
- 暫定レポートが表示された場合は、出典を確認してから再実行する。
