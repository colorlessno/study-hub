# ロール定義

## 基本方針

各ロールは、自分が読む文書と書く成果物を限定する。全情報を読むロールを増やさず、調整役だけが状態をまとめる。

## ロール一覧

| ロール | 責任 | 成果物 |
|---|---|---|
| 調整役 | タスク状態、ロール順序、停止条件の管理 | `task_board.json`、`final_report.md` |
| 計画担当 | 目的、対象外、作業順序、不足情報の整理 | `plan.md` |
| 設計担当 | 構成、データ、境界、失敗時の扱い | `design_note.md` |
| 実行案担当 | 実行案、変更対象、実行しない操作 | `execution_proposal.md` |
| レビュー担当 | 抜け、矛盾、品質リスクの確認 | `review_report.md` |
| QA担当 | 確認観点、機械的検査、受入条件 | `qa_checklist.md` |
| 安全確認担当 | 禁止操作、承認待ち操作、秘密情報確認 | `safety_report.md` |
| 記録担当 | 判断理由、参照成果物、次回引き継ぎ | `decision_log.md` |
