# system03 プロジェクト文書の自然言語Q&A

プロジェクト文書を登録し、質問に関係する箇所を検索して、根拠付きの回答を生成する流れを学ぶテーマです。文書管理、質問と回答、利用状況の分析を画面から確認します。

## このテーマでできるようになること

- 文書を登録し、検索に使う分割データが作成される流れを確認できる
- 質問を送り、回答と根拠文書を照合できる
- 回答への評価が履歴と分析へ反映されることを確認できる
- 文書の再処理と無効化が検索結果へ与える影響を確認できる
- キーワード検索とベクトル検索を組み合わせる理由を説明できる

## 最初に取り組むこと

1. 文書管理画面で教材用サンプル文書を登録し、検索用データの件数と有効状態を確認する。
2. Q&A画面で、登録した文書から答えられる質問を入力する。
3. 回答と一緒に表示された文書名、見出し、抜粋を原文と照合する。
4. 回答を評価し、分析画面の集計へ反映されることを確認する。
5. 文書を再処理または無効化し、検索結果の変化を確認する。

## 画面で確認すること

- 回答だけでなく、回答の根拠となった文書箇所が表示される
- 関係する文書がない質問では、根拠のない回答を生成しない
- 文書の状態を変更すると、検索対象も変わる
- 質問数、回答可否、評価が分析画面で確認できる

## 処理のつながり

```text
文書登録 → 文字列抽出 → 分割 → 検索用データ作成 → 保存
質問入力 → 候補検索 → キーワード・ベクトル評価 → 根拠を付けて回答生成
回答評価 → 履歴保存 → 分析画面へ集計
```

## うまく動かないとき

- 文書一覧で対象文書が有効になっており、検索用データが作成されているか確認する
- 回答できない場合は、質問に対応する記述が登録文書にあるか確認する
- 不適切な根拠が選ばれる場合は、分割内容と検索順位を確認する
- LM Studioで会話用モデルと埋め込みモデルが読み込まれていることを確認する
- 会話用モデルと埋め込みモデルの接続状態を画面のエラー表示と実行ログで確認する
