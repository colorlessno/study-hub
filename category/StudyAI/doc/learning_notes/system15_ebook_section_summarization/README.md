# system15 電子書籍セクション別自動要約

電子書籍のページ取得からOCR、構造解析、図表処理、セクション別要約までを、既存の`book_summarization_cli`で実行するテーマです。StudyHubの画面からジョブを開始し、実行状態とローカルに保存された成果物を確認します。

## このテーマでできるようになること

- 利用権限を確認したPDF、画像フォルダー、または画面キャプチャから要約ジョブを開始できる
- ページ取得、前処理、OCR、構造解析、図表処理、要約生成の状態を実行ログで確認できる
- 目次、見出し、図表を対応付けたセクション別要約を確認できる
- ページ単位の処理結果と成果物の保存先を確認し、完了済み処理を再利用できる

## 最初に取り組むこと

1. 著作権フリーまたは利用許諾済みのPDFか画像フォルダーを用意する。
2. StudyHubからこのテーマを起動し、実行環境に表示されるCLI本体と設定ファイルの確認結果を見る。
3. 入力種別、入力パス、書籍ID、最大ページ数を指定し、利用権限の確認欄を選んでジョブを開始する。処理は一件ずつ順番に実行されるため、完了応答まで画面を閉じない。
4. 完了または失敗として保存されたジョブの状態と実行ログを確認し、セクション一覧と成果物一覧を表示する。

## 画面で確認すること

- 画面から登録した入力が`book_summarization_cli`へ渡され、実際の処理が起動する
- 完了応答後に、ジョブ状態、実行ログ、セクション、成果物をローカルAPIから取得する
- ページ単位の処理結果を保存し、同じ書籍IDの完了済み処理を再利用する
- CLIの失敗を成功として扱わず、終了コードとエラーをジョブへ保存する

## 処理のつながり

ページ画像を前処理し、OCR結果とレイアウト情報を作成します。目次と見出しからセクション境界を判定し、本文と図表説明をセクションごとにまとめて要約します。

## 実行環境

- StudyHubは`category/StudyAI/src/apps/system15_book_summarization_bridge`のローカル連携サービスを起動します。
- 連携サービスはワークスペース直下の`book_summarization_cli`を呼び出します。CLI本体をStudyHub用の簡易処理へ置き換えません。
- Python環境、LM Studio、Tesseract OCRなど、選択したCLIタスクが要求する環境は事前に利用可能にします。
- CLI本体とジョブ成果物はローカルで管理し、GitHubの公開対象には含めません。
- 連携サービスはジョブを一件ずつ処理し、完了後に次のジョブを受け付けます。
