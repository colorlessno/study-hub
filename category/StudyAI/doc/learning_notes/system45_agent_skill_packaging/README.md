# system45 AIエージェント技能のパッケージ化

再利用するAI向けの技能を、技能定義、参照資料、入力検証の処理に分けた構成を確認します。

## このテーマでできるようになること

- 技能定義に必要な入力、出力、制約、手順を説明できる
- 正常な入力と不正な入力を同じ検証処理で判定できる
- 秘密情報を含む入力を処理の前に拒否できる
- 技能定義、参照資料、検証処理の役割を説明できる
- 技能とツール呼び出しの役割の違いを説明できる
- 入力不足、権限不足、危険操作をどの時点で停止するか説明できる

## 最初に取り組むこと

1. 「正常な入力例を検証」を実行し、成功結果を確認する。
2. 「必須項目の不足を検出」と「秘密情報を含む入力を拒否」を実行し、拒否理由を確認する。
3. 「技能定義」と「入力検証の処理」を開き、画面の結果に対応する記述を確認する。
4. 「正常な入力例」と「入力確認表」を開き、入力側で確認する内容を整理する。
5. 下の「技能とツール呼び出しの違い」と「失敗時の扱い」を読み、定義、参照、検証、停止判断の分担を確認する。

## 操作と確認結果

| 操作 | 確認する結果 |
| --- | --- |
| 正常な入力例を検証 | 必須項目が揃い、禁止語がないため成功する |
| 必須項目の不足を検出 | 不足している必須項目が表示される |
| 秘密情報を含む入力を拒否 | 検出した禁止語が表示される |

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `sample_skill/SKILL.md` | 技能の入力、出力、制約、手順を定義する |
| `sample_skill/references/` | 入力例と入力確認表を置く |
| `sample_skill/scripts/validate_input.js` | 入力の必須項目と禁止語を機械的に検証する |

## 技能とツール呼び出しの違い

| 対象 | 担当すること |
| --- | --- |
| 技能 | 作業の目的、入力、出力、制約、参照資料の読み方、停止条件を定める |
| ツール呼び出し | ファイル読取、コマンド実行、API通信など、実際の処理を実行して結果を返す |

技能は作業の進め方を再利用するための定義です。ツール呼び出しは、その手順の中で必要な処理を実行する仕組みです。この教材の`validate_input.js`は、技能全体の判断を代行せず、毎回同じ結果になる入力検証だけを担当します。

## 参照資料を分ける理由

技能定義には毎回必要な短い手順だけを書き、長い確認表や例は`references/`へ分けます。これにより、最初から全資料を読み込まず、必要な資料だけを選んで確認できます。入力検証のように機械的に判定できる処理は`scripts/`へ分けます。

## 失敗時の扱い

| 状況 | 対応 |
| --- | --- |
| 必須入力が不足している | 不足項目を示して処理を停止する |
| 必要な読取・変更権限がない | 権限不足を示し、許可された範囲を確認するまで停止する |
| 削除や上書きなどの危険操作を要求された | 対象と影響を示し、明示的な承認が得られるまで実行しない |
| 秘密情報や個人情報が含まれる | 入力を処理せず、該当する情報を除いて再入力するよう案内する |
