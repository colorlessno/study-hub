# system13 新規参画者向け初期教育エージェント

プロジェクト固有のナレッジを使った質問応答、初期教育項目、教育状況の集計を確認するテーマです。

## このテーマでできるようになること

- 教材用プロジェクトへナレッジを登録できる
- 利用者の役割を指定して質問できる
- 回答と参照元、回答不能時の扱いを確認できる
- 利用者別の初期教育項目と、役割別の初期教育レポートを確認できる
- 未回答質問、初期教育の進み具合、ナレッジ分類を管理状況で確認できる

## 最初に取り組むこと

1. 画面上部の「教材用データを準備」を押し、3件のナレッジが表示されることを確認する。
2. 「質問と回答」で「本番データを更新する前に何を確認しますか」と質問し、回答、参照文書、注意事項を確認する。
3. 「初期教育チェック」でレポートを生成し、チェック項目を未着手から確認中、確認済みへ変更する。
4. 「管理状況」で未回答質問、初期教育の進み具合、ナレッジ分類を確認する。
5. 必要に応じて「ナレッジ」から本文またはファイルを追加し、質問結果が変わることを確認する。

## 画面で確認すること

- 同じタイトルの教材用データを重複登録しない
- プロジェクトごとに参照するナレッジが分かれる
- 回答には参照元または回答不能の理由が示される
- 選択した役割に応じた初期教育項目を作り、状態を更新できる
- 未回答質問と進み具合が低い利用者を管理状況で確認できる

## 処理のつながり

ナレッジ登録で教材用プロジェクトと利用者が作られます。質問処理は登録済みナレッジから根拠を検索して回答を作成し、回答できない質問も履歴へ記録します。初期教育項目とナレッジの分類は管理状況へ集計されます。

## うまく動かないとき

- 先に「教材用データを準備」を実行したか確認する。
- 画面上部のプロジェクトIDを途中で変更していないか確認する。
- 対象プロジェクトにナレッジが登録されているか確認する。
- 回答不能の場合は未回答質問として「管理状況」に記録されているか確認する。
