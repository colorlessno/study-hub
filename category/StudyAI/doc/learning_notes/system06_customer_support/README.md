# system06 問い合わせ対応支援

問い合わせを受け付け、分類、回答案作成、担当者への引き継ぎ、FAQ管理までを扱うテーマです。自動回答できる問い合わせと、人が判断する問い合わせを分けて確認します。

## このテーマでできるようになること

- 問い合わせを登録し、分類結果と回答内容を確認できる
- 自動回答と担当者への引き継ぎをそれぞれ確認できる
- 自動回答への解決可否と満足度を記録できる
- 問い合わせを絞り込み、対応状況を更新できる
- FAQの登録・一括取込と利用状況の集計を確認できる

## 最初に取り組むこと

1. FAQ管理・統計画面で「サンプルFAQを入力」を押し、配送状況のFAQを登録する。
2. 問い合わせ受付・回答画面で「自動回答用サンプル」を送信し、分類、優先度、回答、根拠FAQ、次の操作を確認する。
3. 自動回答へ解決可否と満足度を登録する。
4. 「担当者引き継ぎ用サンプル」を送信し、担当者対応になる理由を確認する。
5. 問い合わせ一覧画面でカテゴリ、優先度、状態を指定して絞り込み、対応状態を更新する。
6. FAQ管理・統計画面で教材用CSVを一括取込し、FAQ件数と問い合わせ統計を確認する。

## 画面で確認すること

- 配送状況の問い合わせに、登録したFAQを根拠とする自動回答が表示される
- 返金、決済トラブル、担当者希望を含む問い合わせが担当者対応になる
- 自動回答への評価を登録できる
- 問い合わせ一覧から対応状態を変更できる
- FAQの登録とCSV取込がFAQ利用数と統計へ反映される

## 処理のつながり

```text
問い合わせ登録 → 内容分類 → 引き継ぎ判定 → FAQ検索・回答作成または担当者へ引き継ぎ
対応結果・評価 → 履歴保存 → 一覧・統計へ反映
```

## うまく動かないとき

- 問い合わせ本文が空でないことを確認する
- 自動回答が表示されない場合は、配送状況のFAQが登録済みか確認する
- 状態変更が反映されない場合は、対象の問い合わせ番号を確認する
- 担当者対応にならない場合は、担当者引き継ぎ用サンプルを再入力して確認する
