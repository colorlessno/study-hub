# system08 タスクの優先順位付け

未経験の作業について、テーマ、現在の状況、背景、制約、担当する役割を入力し、必要なタスクと取り組む順番を確認するテーマです。結果の状態変更、ファイル出力、履歴確認も扱います。

## このテーマでできるようになること

- 未経験の作業と前提条件を入力し、必要なタスクを洗い出せる
- 各タスクの優先度、緊急度、重要度、四象限、依存関係、見積時間を確認できる
- 推奨順と、最初の1週間に順番に行うタスクを確認できる
- 結果の対応状況を更新できる
- MarkdownとCSVで結果を出力できる
- 過去の分析を履歴から再表示できる

## 最初に取り組むこと

1. 「教材用の入力例を使う」を押し、設定されたテーマ、現在の状況、背景、制約、役割を確認する。
2. 「分析開始」を押し、タスク数、見積時間、推奨順、四象限ごとのタスクを確認する。
3. タスクの状態を「進行中」へ変更して保存する。
4. MarkdownとCSVを出力し、画面に表示されたタスクが含まれることを確認する。
5. 分析履歴を開き、保存した分析を再表示する。

## 画面で確認すること

- 現在の状況や制約が、タスクの説明や注意点に反映される
- 優先度だけでなく、緊急度、重要度、四象限、依存関係を一緒に確認できる
- 参照情報があるタスクでは、根拠にしたページを開ける
- 状態変更が結果画面と履歴画面へ反映される
- 出力内容に画面で確認した結果が含まれる

## 処理のつながり

```text
作業情報入力 → タスク洗い出しAPI → 優先度・四象限・依存関係を計算 → 結果を保存・表示
状態変更 → 結果を更新 → 履歴へ反映
出力要求 → 保存済み結果をMarkdownまたはCSVへ変換
```

## うまく動かないとき

- テーマが入力されているか確認する
- 結果が不自然な場合は、現在の状況、背景、制約、役割を具体的に入力する
- 出力できない場合は、分析結果が保存済みか確認する
