# system01 請求書・領収書の項目抽出

請求書や領収書を登録し、AIが抽出した項目を確認・訂正する流れを学ぶテーマです。1件の抽出だけでなく、一括処理、検索、確認状態、CSV出力まで画面から確認します。

## このテーマでできるようになること

- 文書を登録し、抽出された項目と信頼度を確認できる
- 一括処理の進行状況と失敗した文書を確認できる
- 抽出結果を検索し、CSVで出力できる
- 訂正内容を保存し、確認状態を未確認から確認済みへ更新できる
- 画面、API、抽出指示、テストのつながりを説明できる

## 最初に取り組むこと

1. 抽出実行画面で請求書または領収書を登録する。
2. 抽出結果の金額、日付、発行元などを元の文書と照合する。
3. 誤った項目を訂正し、保存後の表示を確認する。
4. 一括ジョブ確認画面で処理件数と失敗件数を確認する。
5. 抽出結果一覧で検索とCSV出力を試す。

## 画面で確認すること

- 読み取れなかった項目が、確定値と区別して表示される
- 一括処理の受付、処理中、完了、失敗を判別できる
- 訂正後の値と確認状態がDBへ保存され、一覧に反映される
- 訂正操作が処理ログへ記録される
- CSV出力は確認状態を指定しない場合、確認済みデータだけを対象にする
- 検索条件を変えると一覧と出力対象が変わる

## 処理のつながり

```text
文書登録 → 抽出API → 抽出指示を使った項目解析 → 結果保存 → 画面表示
訂正入力 → 訂正API → 値・確認状態の更新と操作ログ保存 → 一覧へ反映
```

## うまく動かないとき

- 文書の形式とファイルサイズを確認する
- 実行ログで、文書登録、抽出、保存のどこで失敗したか確認する
- 一括処理では、全体件数だけでなく失敗した文書の内容も確認する
