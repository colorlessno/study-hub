# system19 Attentionの関係表示

文章を単語へ分割し、単語同士の関係を正方行列として表示する仕組みを確認するテーマです。

## このテーマでできるようになること

- 文章を分割した単語と行列の対応を確認できる
- 行列の行数と列数が単語数と一致することを確認できる
- 注目する単語の位置を変えて関係値を比較できる
- 指示語と先行語、修飾語と直後の語に加算される疑似スコアを比較できる
- 簡易的な関係値と実際のAIモデルのAttentionを区別できる

## 最初に取り組むこと

1. 「実験条件」の`sentence`に、単語を空白で区切った比較文を入力する。
2. `focus_token_index`に、指示語または修飾語の位置を入力する。
3. 「実行」を押し、分割した単語と関係行列を確認する。
4. 注目位置や文章を変更し、行列の変化を比較する。

## 画面で確認すること

- 行列の各行と各列が分割した単語に対応する
- 同じ単語自身の値が大きく表示される
- 近い位置にある単語ほど値が大きくなる
- 指示語とその前の参照候補、修飾語と直後の語に関係値が加算される
- 関係値の加算理由が`relation_reasons`へ表示される
- 範囲外の注目位置は有効な範囲へ補正される
- 保存状態を確認し、バックエンド再起動後も過去の結果を再表示できる

## 処理のつながり

画面から文章と注目位置をAPIへ送り、簡易分割処理が単語の一覧を作ります。単語同士の位置と一致関係に加え、指示語と先行語、修飾語と直後の語へ値を加算し、関係行列、注目位置の値、加算理由を画面へ返します。入力と結果はホスト側データ領域のJSONへ保存します。

## この実験で確認できる範囲

この行列は単語の位置、一致、指示語、修飾語を使って作った値です。Transformerが計算したAttentionの値ではなく、AIモデルの判断理由を示すものでもありません。

## うまく動かないとき

- `sentence`が文字列になっているか確認する。
- `focus_token_index`が整数になっているか確認する。
- StudyAIの共有環境が起動しているか確認する。
