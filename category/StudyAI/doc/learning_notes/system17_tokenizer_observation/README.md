# system17 トークン分割の観察

文章を簡易規則で分割し、文字数と推定トークン数、入力上限の関係を確認するテーマです。

## このテーマでできるようになること

- 文字数と推定トークン数の違いを確認できる
- 日本語、英語、記号がどのように分割されるか比較できる
- 推定トークン数が入力上限を超えたか確認できる
- 簡易分割と実際のAIモデルのトークン分割を区別できる

## 最初に取り組むこと

1. 「サンプル文を選ぶ」から日本語、英語、記号と改行、日本語と英語のいずれかを選ぶ。
2. 「実行」を押し、文字数、推定トークン数、分割結果、注意点メモを確認する。
3. 別のサンプルを選び、言語、空白、改行、記号による違いを比較する。
4. `context_limit`を小さくして再実行し、上限超過の表示と注意点メモの変化を確認する。

## 画面で確認すること

- 空白、句読点、英数字が別々の要素として表示される
- 文章の文字数と分割された要素数は一致しない
- 推定トークン数が上限を超えると「上限を超えたか」が「はい」になる
- 注意点メモに簡易分割の制約と上限超過時の対応が表示される
- 実行履歴から過去の入力と結果を再表示できる
- 保存状態を確認し、バックエンド再起動後も過去の結果を再表示できる

## 処理のつながり

サンプル文と既定値はAPIから取得します。選択または編集した文章をAPIへ送ると、サーバー側の簡易分割処理が文字列を分割します。分割数と入力上限を比較し、文字数、推定トークン数、分割結果、上限超過の有無、注意点メモを画面へ返し、実行履歴をホスト側データ領域のJSONへ保存します。

## この実験で確認できる範囲

この画面の分割結果は正規表現を使った推定値です。GPTやClaudeなどが実際に使用するトークン分割ではありません。料金や入力上限を正確に判断するときは、使用するモデルと同じトークナイザーで計測します。

## うまく動かないとき

- 「実験条件」がJSON形式になっているか確認する。
- `context_limit`が数値になっているか確認する。
- StudyAIの共有環境が起動しているか確認する。
