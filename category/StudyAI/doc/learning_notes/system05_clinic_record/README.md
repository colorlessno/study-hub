# system05 診療記録と予約管理

患者情報と診療内容を登録し、SOAP形式のカルテ生成、訂正履歴、予約受付、月次統計、バックアップまでを一つの画面で確認するテーマです。

## このテーマでできるようになること

- 患者を登録し、患者一覧から詳細・カルテ・予約を確認できる
- 施術日、時間、メニュー、料金、施術メモからSOAP形式のカルテを生成できる
- 生成されたカルテを理由付きで訂正し、訂正前後の内容を確認できる
- 空き枠から予約を登録し、予約状態と月次統計を確認できる
- バックアップを実行し、実行履歴を確認できる

## 最初に取り組むこと

1. 患者一覧画面で「教材用サンプルを入力」を押し、患者を登録する。
2. 登録した患者の詳細を開き、患者IDを引き継いでカルテ生成画面へ進む。
3. 「教材用サンプルを入力」を押し、施術日、時間、メニュー、料金、施術メモからカルテを生成する。
4. 主観情報・客観情報・評価・計画と、次回提案、注意事項を確認する。
5. 評価または計画を変更し、訂正理由を入力して保存する。訂正履歴で訂正前後を確認する。
6. 院内予約受付画面で空き枠を選んで予約し、予約管理画面で状態を更新する。
7. 月次統計を取得し、予約件数、完了件数、キャンセル、新患、売上、再来率を確認する。
8. バックアップを実行し、履歴に状態、保存先、完了時刻が記録されることを確認する。

## 画面で確認すること

- 患者詳細に登録した患者情報、カルテ、予約がまとめて表示される
- 患者の禁忌事項と施術メモに応じた注意事項がカルテに表示される
- 訂正前と訂正後のSOAP内容が履歴に分けて表示される
- 院内予約受付で発行された予約番号と、予約管理画面の予約が一致する
- 予約状態の更新内容が月次統計に反映される
- バックアップ履歴に成功または失敗の状態が残る

## 処理のつながり

```text
患者登録 → 患者情報を保存 → 施術条件とメモを入力 → SOAP形式のカルテを生成
カルテを訂正 → 訂正理由と訂正前後の内容を履歴へ保存
空き枠を検索 → 予約を登録 → 予約状態を更新 → 月次統計へ反映
バックアップを実行 → 実行結果と保存先を履歴へ保存
```

## うまく動かないとき

- カルテを生成できない場合は、患者ID、施術日、時間、メニュー、料金、施術メモを確認する
- 空き枠が表示されない場合は、翌日以降の日付、メニュー、所要時間を確認する
- 予約できない場合は、患者IDと本人確認用の生年月日または電話番号下4桁を確認する
- 統計が変わらない場合は、予約日と集計対象月が一致しているか確認する
