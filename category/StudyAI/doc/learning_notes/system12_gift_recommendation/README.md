# system12 コンシェルジュ・推薦システム

会話から贈り物の条件を整理し、商品、シーン、除外規則、推薦履歴を組み合わせて候補を提示するテーマです。

## このテーマでできるようになること

- 会話から相手、用途、予算などの条件を確認できる
- 商品の登録、一覧確認、有効・無効の切り替えを操作できる
- シーンと除外規則が推薦候補に与える影響を説明できる
- 商品別の推薦回数と評価件数を確認できる

## 最初に取り組むこと

1. 「商品管理画面」で入力済みの教材用商品を登録し、一覧へ表示されることを確認する。
2. 「オントロジー・分析画面」で入力済みのシーンと除外規則を登録する。
3. 「会話推薦画面」で入力済みの依頼を送り、収集された条件、推薦候補、推薦理由を確認する。
4. 推薦候補へ評価を送り、「オントロジー・分析画面」の推薦統計を更新する。
5. 商品を無効にして同じ依頼を送り、推薦対象から外れることを確認した後、商品を有効へ戻す。

## 画面で確認すること

- 条件が足りない場合は追加質問が表示される
- 商品名、価格、タグ、適したシーン、適した相手を使って推薦候補を絞り込む
- 除外規則の語句、対象シーン、対象者、判定方法を使って候補を除外または注意表示する
- 推薦履歴から商品別の推薦回数と評価件数を集計する

## 処理のつながり

会話処理が依頼内容を整理し、検索処理が商品候補を取得します。規則判定がシーンと除外条件を適用し、推薦処理が理由付きの候補を返します。推薦と評価の履歴は分析画面で集計します。

## うまく動かないとき

- Docker Desktopが起動しているか確認する。
- LM Studioに会話モデルが読み込まれているか確認する。読み込まれていない場合でも、入力中の既知の語句は規則による条件抽出で確認できる。
- 商品が有効になっているか確認する。
- 会話に相手、用途、予算などの条件が含まれているか確認する。
- 失敗した場合は、画面上部に表示されるAPIのエラー内容を確認する。
