# system04 レビュー分析

レビュー文を分析し、評価傾向、話題、感情、比較結果を確認するテーマです。JSON入力、ファイル入力、商品比較、分析履歴を扱います。

## このテーマでできるようになること

- 複数のレビューをJSONで分析し、感情と話題を確認できる
- CSV・JSON・TXTファイルからレビューを取り込み、分析対象件数を確認できる
- 商品ごとの分析結果を比較できる
- 条件を指定して分析履歴を検索できる
- 入力から集計結果までの処理の流れを説明できる

## 最初に取り組むこと

1. 単一分析画面でサンプルの商品名とレビューを使い、分析結果を確認する。
2. 表示された感情、話題、要約を入力文と照合する。
3. ファイル分析画面で教材用サンプルファイルを用意し、取り込まれたレビュー数を確認する。
4. 比較分析画面のサンプルJSONで2つの商品を比較し、傾向の差を確認する。
5. 分析履歴画面で条件を変えて検索し、「結果を表示」で保存済みの内容を再表示する。

## 画面で確認すること

- 入力内容に対応する感情と話題が表示される
- ファイルの内容に対応する商品名と分析対象件数が表示される
- 比較結果で、件数と割合を混同せず確認できる
- 履歴から同じ分析結果を再表示できる

## 処理のつながり

```text
レビュー入力 → 分析API → 感情・話題・要約の生成 → 結果保存 → 画面表示
複数結果 → 商品単位で集計 → 比較画面と履歴画面へ反映
```

## うまく動かないとき

- ファイルの列名と文字コードを確認する
- 失敗行がある場合は、対象行の入力形式を確認する
- 比較結果が空の場合は、比較用JSONに2商品以上と各商品のレビューが含まれるか確認する
