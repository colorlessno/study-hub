# system07 文書の自動タグ付けと類似推薦

文書を登録すると、AIがカテゴリ・文書種別・重要度・タグ・要約を作成します。登録済み文書の検索、類似文書の推薦、タグの変更と統合、利用状況の確認までを一つの画面で体験するテーマです。

## このテーマでできるようになること

- 文書の内容からタグと要約が作られる流れを確認できる
- 同じ内容の文書がファイル名に関係なく重複として拒否されることを確認できる
- キーワード検索と意味の近さを使う検索の違いを確認できる
- 文書詳細と類似文書を表示し、登録内容を比較できる
- タグの変更と統合が文書と利用状況へ反映されることを確認できる

## 最初に取り組むこと

1. 「文書登録」で「API設計サンプルを選ぶ」を押し、文書を登録する。
2. 表示されたカテゴリ、文書種別、重要度、タグ、要約をサンプル本文と照合する。
3. 同じ「API設計サンプル」をもう一度登録し、重複を知らせるメッセージを確認する。
4. 「類似文書サンプルを選ぶ」を押し、2件目の文書を登録する。
5. 「文書を探す」で検索方法を切り替え、文書一覧と件数の違いを確認する。
6. 一覧の「詳細」を押し、登録者、閲覧権限、閲覧数、類似文書を確認する。
7. 詳細画面でタグとカテゴリを変更し、文書一覧へ反映されることを確認する。
8. 「タグ・利用状況」で2つのタグを統合し、タグ一覧とアクセス回数を確認する。

## 画面で確認すること

- 登録処理の成功と失敗が画面上のメッセージで区別できる
- 文書本文と自動生成された分類、タグ、要約に関連がある
- キーワード、カテゴリ、タグ、文書種別、重要度で検索結果を絞り込める
- 文書詳細を開くと閲覧数が増え、類似文書が類似度とともに表示される
- タグの変更と統合後に、文書一覧とタグ利用件数が更新される

## 処理のつながり

```text
文書登録 → 文字列抽出 → 重複確認 → 埋め込み生成 → タグ・要約生成 → 文書を保存
検索条件 → キーワード検索または意味検索 → 文書一覧 → 詳細・類似文書
タグ変更・統合 → 文書とタグの関連を更新 → タグ利用件数へ反映
詳細・検索・推薦の利用 → アクセス履歴を保存 → 利用状況へ反映
```

## うまく動かないとき

- 登録できない場合は、対応している拡張子と文書本文が空でないことを確認する
- 自動タグ付けに失敗した場合は、LM Studioが起動し、設定したポートで応答していることを確認する
- 検索結果が想定と違う場合は、検索条件を一つずつ外して対象文書を確認する
- タグ統合を選べない場合は、異なるタグを持つ文書を2件以上登録する
