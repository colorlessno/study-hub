# 小さなレビューを行う技能

証拠に基づいて、対象ファイルの小さなレビューを行います。

## 入力

- `task_goal`: レビューの目的
- `target_file`: 対象ファイル
- `expected_output`: 期待する出力

## 出力

- レビュー結果の要約
- 根拠を示した指摘事項
- 残っているリスク

## 制約

- 秘密情報や個人情報を入力へ含めない。
- 対象ファイルが存在しない場合は処理を停止する。
- スクリプトは結果が毎回同じになる検証だけに使う。

## 参照資料

- 入力例を確認するときは`references/examples.md`を読む。
- 実行前後の確認観点が必要なときは`references/checklist.md`を読む。
- 参照資料は必要なものだけを読み、すべてを一度に読み込まない。

## 手順

1. 入力の必須項目と禁止語を検証する。
2. 対象ファイルと必要な参照資料を読む。
3. 根拠を示した指摘事項をまとめる。
4. 結果の要約と残っているリスクを出力する。

## 失敗時の扱い

- 必須入力が不足している場合は、不足項目を示して停止する。
- 対象ファイルを読む権限がない場合は、権限不足を示して停止する。
- 削除や上書きなどの危険操作を要求された場合は、対象と影響を示し、明示的な承認を得るまで実行しない。
- 秘密情報や個人情報が含まれる場合は処理せず、該当情報を除いた入力を求める。
- 入力検証の処理が失敗した場合は、エラー内容と再実行に必要な条件を示す。
