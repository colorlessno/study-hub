# 設計メモ

## 構成

タスクボード、ロール定義、共有記憶、ロール成果物、実行ログを分ける。

## データ

- `task_board.json`: タスク状態と承認待ち
- `role_catalog.json`: ロールの責任境界
- `run_log.json`: 実行結果と確認結果

## 境界

AIロールは自分の担当成果物だけを作る。危険操作は実行せず、安全確認に渡す。

## 失敗時の扱い

目的や制約が不足した場合は停止する。`local_llm`でLM Studioへ接続できない場合は失敗理由を保存して停止し、模擬実行が必要なら別の実行として`mock`を明示的に選ぶ。
