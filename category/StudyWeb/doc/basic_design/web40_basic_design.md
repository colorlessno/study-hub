# web40 テーブル検索・ページ分割 基本設計

## 設計の目的

17件の固定データを使い、一覧の検索、絞り込み、並べ替え、ページ分割、表示状態を一つの画面で確認できるようにします。

## 画面から受け取る値

| 入力 | 内容 |
|---|---|
| 名前検索 | 名前の部分一致に使う文字列 |
| 対応状況 | すべて、対応中、完了 |
| 名前順 | 昇順または降順 |
| 現在ページ | 0から始まるページ番号 |
| 表示状態 | 通常表示、読込中、読込エラー |

## 画面へ表示する値

| 出力 | 内容 |
|---|---|
| 一覧表 | 番号、名前、対応状況 |
| 件数情報 | 絞り込み後の件数、表示範囲、現在ページ、総ページ数 |
| 検索結果なし | 条件に一致するデータがないこと |
| 読込中 | 処理中であること |
| 読込エラー | 処理に失敗したことと通常表示へ戻す案内 |
| ページボタン | 現在ページに応じた有効・無効状態 |

## 一覧を作る順番

1. 名前と対応状況で対象を絞り込む。
2. 絞り込んだ全件を名前順に並べ替える。
3. 総ページ数を計算し、現在ページを存在する範囲内へ補正する。
4. 現在ページに表示する5件を取り出す。
5. 一覧、件数情報、ページボタンの状態を更新する。

## 画面状態の扱い

- 通常表示では、一覧計算の結果を表示する。
- 検索結果が0件なら、検索結果なしとして表示する。
- 読込中と読込エラーは学習用に選択でき、ページ移動を無効にする。
- 通常表示へ戻すと、現在の検索条件から一覧を再計算する。

## 確認すること

- 操作を組み合わせても、ページ番号が存在する範囲を超えない
- 検索結果なしと読込エラーを別の状態として表示する
- ラベル、表見出し、ボタンの無効状態を画面で確認できる
- 長い名前を表示しても表の幅が崩れない
