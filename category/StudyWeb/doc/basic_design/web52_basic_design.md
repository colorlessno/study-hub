# web52 基本設計

## 画面の構成

| 領域 | 役割 |
|---|---|
| 利用場面 | 比較対象を選び、前提条件と検討の手掛かりを表示する |
| 表示方式 | MPA、SPA、SSR、SSGから基本となる方式を1つ選ぶ |
| 組み合わせる仕組み | Server Components、Islands、PWAを複数選択できる |
| 判断メモ | 選定理由等の5項目を入力する |
| 操作 | 現在の判断メモを保存または削除する |
| 保存内容 | 現在の利用場面について保存した内容を表示する |

## 操作の流れ

```text
利用場面を選ぶ
  ↓
条件と検討の手掛かりを読む
  ↓
基本となる方式と組み合わせる仕組みを選ぶ
  ↓
判断メモを入力する
  ↓
ブラウザ内に保存する
  ↓
別の利用場面と比較する
```

## データの扱い

利用場面、表示方式、組み合わせる仕組みはJavaScript内の固定データとする。判断メモは利用場面IDをキーにして `localStorage` へ保存する。外部通信は行わない。

## 入力確認

保存時に次を確認する。

- MPA、SPA、SSR、SSGのいずれかが選ばれている
- 選定理由が入力されている

入力が不足している場合は保存せず、画面内に不足内容を表示する。
