# web05 基本設計
## レスポンシブなカード一覧レイアウト

---

## 1. システム構成設計

### 1.1 全体構成

```text
ブラウザ
  ↓
index.html
  └─ styles.css
      ├─ Grid / Flexbox
      └─ Media Query
```

### 1.2 コンポーネント一覧

| コンポーネント | 役割 |
|---|---|
| `index.html` | ヘッダー、カード一覧、フッターを定義 |
| `styles.css` | カード配置、余白、レスポンシブ表示を定義 |
| `doc/learning_notes/web05_responsive_layout/README.md` | 画面幅ごとの確認手順を説明 |

---

## 2. 主要設計方針

### 2.1 レイアウト方針

- カード一覧は CSS Grid または Flexbox で配置する
- PC幅では複数列、スマートフォン幅では1列にする
- 横スクロールが発生しないよう `max-width` と `gap` を調整する

### 2.2 UI方針

- カードにはタイトル、説明、カテゴリ、ボタンを配置する
- 余白と行間を確保し、読みやすさを優先する
- JavaScript は必須にしない

---

## 3. IF仕様

### 3.1 表示IF

| 条件 | 表示 |
|---|---|
| PC幅 | カードを複数列表示 |
| タブレット幅 | カード列数を縮小 |
| スマートフォン幅 | カードを1列表示 |

### 3.2 ファイル参照IF

| 呼び出し元 | 参照先 | 目的 |
|---|---|---|
| `index.html` | `styles.css` | レスポンシブスタイル適用 |

---

## 4. 処理フロー

```text
ページ表示
  ↓
CSSを読み込む
  ↓
画面幅に応じてメディアクエリを適用
  ↓
カード一覧を適切な列数で表示
```

---

## 5. データ設計

DBは使用しない。カード内容はHTMLに固定で記述する。

| データ | 保持場所 | 用途 |
|---|---|---|
| カードタイトル | HTML | 一覧表示 |
| カード説明 | HTML | 内容説明 |
| カテゴリ | HTML | カード分類 |

---

## 6. プロンプト・AI制御設計

AI処理は使用しない。

---

## 7. ガードレール・エラー処理設計

- 長いテキストがカード外へはみ出さないようにする
- 小さい画面で横スクロールが出ないことを確認する
- DevTools のデバイスモードで表示を確認する

---

## 8. 非機能・運用設計

- 外部CSSフレームワークは使わない
- ローカルファイルで確認できる
- レスポンシブ確認は PC幅とスマートフォン幅を必須にする
