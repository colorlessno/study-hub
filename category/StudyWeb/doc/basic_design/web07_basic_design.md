# web07 基本設計
## Reactカウンター

---

## 1. システム構成設計

### 1.1 全体構成

```text
ブラウザ
  ↓
Vite Dev Server
  ↓
React App
  └─ App.tsx
      ├─ useState
      └─ onClick handlers
```

### 1.2 コンポーネント一覧

| コンポーネント | 役割 |
|---|---|
| `main.tsx` | ReactアプリをDOMへマウントする |
| `App.tsx` | カウンター状態と操作ボタンを持つ |
| `App.css` | カウンター画面の見た目を定義する |
| `doc/learning_notes/web07_react_counter/README.md` | 起動方法と state の確認ポイントを説明する |

---

## 2. 主要設計方針

### 2.1 React設計方針

- カウント値は `useState` で管理する
- 加算、減算、リセットはイベントハンドラとして定義する
- state の変更に応じて再描画されることを画面で確認する

### 2.2 UI設計方針

- 現在値を大きく表示する
- 操作ボタンは加算、減算、リセットの3種類にする
- 初学者が処理を追えるよう、コンポーネントは最小構成にする

---

## 3. IF仕様

### 3.1 画面イベントIF

| イベント | 処理 | 出力 |
|---|---|---|
| 加算クリック | `count + 1` | 表示値更新 |
| 減算クリック | `count - 1` | 表示値更新 |
| リセットクリック | `count = 0` | 表示値を0へ戻す |

### 3.2 コンポーネントIF

本サンプルは単一 `App` コンポーネントで構成し、props は使用しない。

## 4. 処理フロー

```text
npm run dev
  ↓
Vite Dev Server 起動
  ↓
ブラウザでReactアプリ表示
  ↓
ボタンクリック
  ↓
setCount 実行
  ↓
Reactが再描画
```

## 6. プロンプト・AI制御設計

AI処理は使用しない。

---

## 7. ガードレール・エラー処理設計

- `useState` の更新は現在値から計算する
- 依存ライブラリが未導入の場合は `npm install` を実行する
- Vite起動ポートが使用中の場合は別ポートで起動する

---

## 8. 非機能・運用設計

- Vite + React + TypeScript を使用する
- 外部状態管理ライブラリは使用しない
- 起動と確認が短時間で完了する構成にする
