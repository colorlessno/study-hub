# web06 基本設計
## 入力フォームとバリデーション

---

## 1. システム構成設計

### 1.1 全体構成

```text
ブラウザ
  ↓
index.html
  ├─ styles.css
  └─ script.js
      ├─ 入力値取得
      ├─ バリデーション
      └─ 結果表示
```

### 1.2 コンポーネント一覧

| コンポーネント | 役割 |
|---|---|
| `index.html` | フォーム要素を定義 |
| `styles.css` | 入力欄、エラー、ボタンの見た目を定義 |
| `script.js` | 入力チェック、成功/エラー表示を担当 |
| `doc/learning_notes/web06_form_basic/README.md` | 入力例と確認手順を説明 |

---

## 2. 主要設計方針

### 2.1 フォーム設計方針

- 名前、メールアドレス、問い合わせ種別、本文を入力対象とする
- 必須項目が分かる表示にする
- 入力欄の近くにエラーを表示する

### 2.2 バリデーション方針

- JavaScript で submit イベントを処理する
- 未入力とメール形式不正を検出する
- 正常時はページ遷移せず成功メッセージを表示する

---

## 3. IF仕様

### 3.1 入力IF

| 項目 | 種別 | 必須 | チェック |
|---|---|---|---|
| 名前 | text | yes | 空文字不可 |
| メールアドレス | email | yes | 形式チェック |
| 問い合わせ種別 | select | yes | 未選択不可 |
| 本文 | textarea | yes | 空文字不可 |

### 3.2 イベントIF

| イベント | 処理 | 出力 |
|---|---|---|
| submit | 入力検証 | 成功またはエラー表示 |
| reset | 入力値とメッセージを初期化 | 初期状態 |

---

## 4. 処理フロー

```text
フォーム入力
  ↓
送信ボタンクリック
  ↓
preventDefault
  ↓
入力値取得
  ↓
バリデーション
  ├─ OK: 成功メッセージ表示
  └─ NG: エラーメッセージ表示
```

---

## 5. データ設計

DBは使用しない。

| データ | 保持場所 | 用途 |
|---|---|---|
| 入力値 | form element | バリデーション対象 |
| エラーメッセージ | JavaScript | 画面表示 |
| 成功メッセージ | JavaScript | 送信完了表示 |

---

## 6. プロンプト・AI制御設計

AI処理は使用しない。

---

## 7. ガードレール・エラー処理設計

- 空欄送信を防ぐ
- 不正なメール形式を検出する
- エラーは入力欄の近くに表示する
- 実送信や外部API呼び出しは行わない

---

## 8. 非機能・運用設計

- 外部フレームワークは使わない
- スマートフォン幅でも入力しやすくする
- ブラウザ標準のフォーム要素を利用する
