# web01 基本設計
## 静的自己紹介ページ

---

## 1. システム構成設計

### 1.1 全体構成

```text
学習者
  ↓
ブラウザ
  ↓
index.html
  ├─ styles.css
  └─ script.js
```

本サンプルは、HTML / CSS / JavaScript の役割分担を学ぶための最小構成の静的Webページである。
Webサーバー、API、データベース、ビルドツールは使用しない。

### 1.2 コンポーネント一覧

| コンポーネント | 役割 |
|---|---|
| `index.html` | ページ構造、自己紹介文、ボタン、表示領域を定義する |
| `styles.css` | 背景色、文字色、余白、カード風レイアウトなどの見た目を定義する |
| `script.js` | ボタンクリック時の表示変更を担当する |
| `doc/learning_notes/web01_static_first_page/README.md` | サンプルの目的、操作手順、学習ポイントを説明する |

## 2. 主要設計方針

### 2.1 HTML設計方針

- 自己紹介ページとして、見出し、プロフィール概要、箇条書き、操作ボタン、結果表示領域を配置する
- HTML は構造を表すことに集中し、見た目の指定は CSS に寄せる
- JavaScript から取得する要素には `id` または分かりやすい class 名を付ける

### 2.2 CSS設計方針

- CSS は `styles.css` に分離する
- ページ全体の余白、背景色、文字色、カード風の見た目を指定する
- 初学者が読みやすいよう、セレクタ数と装飾量は最小限にする

### 2.3 JavaScript設計方針

- JavaScript は `script.js` に分離する
- ボタンをクリックしたときに、画面上の表示領域を書き換える
- DOM操作は `document.querySelector` または `document.getElementById` を使う
- HTML の `onclick` 属性には処理を書かず、JavaScript ファイル側でイベントを登録する

## 3. IF仕様

### 3.1 ファイル参照IF

| 呼び出し元 | 参照先 | 方式 | 目的 |
|---|---|---|---|
| `index.html` | `styles.css` | `<link rel="stylesheet">` | 見た目の適用 |
| `index.html` | `script.js` | `<script defer>` | クリックイベントの登録 |

### 3.2 画面イベントIF

| イベント | 発生元 | 処理 | 出力 |
|---|---|---|---|
| 初期表示 | ブラウザ | HTML / CSS / JS を読み込む | 自己紹介ページを表示 |
| クリック | あいさつ表示ボタン | JavaScript で表示領域を書き換える | あいさつ文または補足メッセージを表示 |

### 3.3 DOM要素一覧

| 要素ID | 種別 | 用途 |
|---|---|---|
| `messageButton` | button | クリック操作の起点 |
| `messageOutput` | p または div | JavaScript による表示変更先 |

## 4. 処理フロー

### 4.1 初期表示

```text
ブラウザで index.html を開く
  ↓
HTML を読み込む
  ↓
styles.css を読み込む
  ↓
script.js を読み込む
  ↓
自己紹介ページを表示する
```

### 4.2 ボタンクリック

```text
学習者がボタンをクリック
  ↓
JavaScript のイベントハンドラが実行される
  ↓
表示メッセージを作成する
  ↓
messageOutput の textContent を更新する
```

## 7. ガードレール・エラー処理設計

- `script.js` の読み込み順序問題を避けるため、`<script defer>` を使用する
- JavaScript で対象要素を取得できない場合は、処理を中断し Console にエラーを出す
- CSS や JavaScript が読み込まれない場合は、DevTools の Console / Network で確認できるよう README に案内する
- 外部ライブラリを使用しないため、ネットワーク未接続でも動作する

---

## 8. 非機能・運用設計

- ローカルファイルとして `index.html` を開くだけで動作する
- ビルド手順は不要とする
- インターネット接続なしで動作する
- 初学者が1ファイルずつ読めるよう、コード量を抑える
- 対応ブラウザは、最新の Chrome / Edge / Firefox を想定する

## 15. シーケンス図

### 15.1 初期表示

```text
学習者 -> ブラウザ: index.html を開く
ブラウザ -> index.html: HTML 読み込み
index.html -> styles.css: CSS 読み込み
index.html -> script.js: JavaScript 読み込み
ブラウザ -> 学習者: 自己紹介ページを表示
```

### 15.2 ボタンクリック

```text
学習者 -> ブラウザ: ボタンをクリック
ブラウザ -> script.js: click イベント発火
script.js -> index.html: messageOutput を更新
ブラウザ -> 学習者: 更新後メッセージを表示
```
