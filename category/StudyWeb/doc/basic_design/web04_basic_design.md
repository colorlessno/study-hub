# web04 基本設計
## 素のJavaScriptによるDOM操作

---

## 1. システム構成設計

### 1.1 全体構成

```text
ブラウザ
  ↓
index.html
  ├─ styles.css
  └─ script.js
      ├─ DOM要素取得
      ├─ イベント登録
      └─ 表示更新
```

### 1.2 コンポーネント一覧

| コンポーネント | 役割 |
|---|---|
| `index.html` | ボタン、表示結果エリアを定義 |
| `styles.css` | 操作しやすい画面スタイルを定義 |
| `script.js` | 要素取得、イベント処理、表示変更を担当 |
| `doc/learning_notes/web04_vanilla_dom/README.md` | DOM操作の確認手順を説明 |

---

## 2. 主要設計方針

### 2.1 DOM操作方針

- JavaScript から対象要素を取得する
- `addEventListener` でイベントを登録する
- `textContent` により表示を更新する
- HTML の `onclick` 属性は使わない

### 2.2 画面設計方針

- 操作ボタンと表示結果エリアを明確に分ける
- 初期状態とクリック後の状態が分かる表示にする
- React に進む前の前提知識として、ブラウザ標準APIに集中する

---

## 3. IF仕様

### 3.1 DOM IF

| 要素ID | 種別 | 用途 |
|---|---|---|
| `changeButton` | button | 表示変更イベントの起点 |
| `resetButton` | button | 表示を初期化する |
| `resultText` | div | 表示結果の出力先 |

### 3.2 イベントIF

| イベント | 処理 | 出力 |
|---|---|---|
| 変更ボタンクリック | メッセージを生成 | `resultText` を更新 |
| リセットボタンクリック | 初期メッセージに戻す | `resultText` を初期化 |

---

## 4. 処理フロー

```text
ページ読み込み
  ↓
script.js がDOM要素を取得
  ↓
ボタンに click イベントを登録
  ↓
学習者がボタンをクリック
  ↓
表示結果エリアを更新
```

---

## 5. データ設計

DBは使用しない。

| データ | 保持場所 | 用途 |
|---|---|---|
| 初期メッセージ | JavaScript | 初期表示 |
| クリック後メッセージ | JavaScript | 表示更新 |
| クリック回数 | JavaScript変数 | 動作確認 |

---

## 6. プロンプト・AI制御設計

AI処理は使用しない。

---

## 7. ガードレール・エラー処理設計

- DOM取得に失敗した場合は処理を中断する
- `script` は `defer` 付きで読み込む
- Console でエラーを確認できるよう README に手順を記載する

---

## 8. 非機能・運用設計

- 外部フレームワークは使わない
- ビルド不要で動作する
- JavaScript の行数を抑え、処理の流れを追いやすくする
- 最新ブラウザを想定する
