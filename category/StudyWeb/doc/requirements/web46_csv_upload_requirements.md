# web46 CSVアップロード 要件定義

## 1. 目的

業務ファイル取込の基本として、CSVアップロード、検証、プレビュー、取込結果表示を学ぶ。

## 2. 学習対象

- multipart/form-data
- CSV parsing
- file size limit
- validation
- preview
- import result

## 3. 作成する成果物

- CSVアップロード画面
- CSV検証API
- プレビュー表示
- エラー行表示
- 取込結果メモ

## 4. 機能要件

| ID | 要件 |
|---|---|
| FR-01 | CSVファイルを選択してアップロードできる |
| FR-02 | 拡張子、サイズ、必須列を検証できる |
| FR-03 | 先頭数行をプレビューできる |
| FR-04 | 行単位エラーを表示できる |
| FR-05 | 取込成功件数と失敗件数を表示できる |

## 5. 非機能要件

| ID | 要件 |
|---|---|
| NFR-01 | 大きすぎるファイルを拒否する |
| NFR-02 | エラー理由を利用者が修正できる形で返す |
| NFR-03 | ファイル保存やS3は後続テーマに分ける |

## 6. 対象外

- S3保存
- 非同期ジョブ化
- ウイルススキャン
- 本格文字コード自動判定

## 7. 受入条件

- 正常CSVと異常CSVを確認できる
- 行単位エラーを説明できる
- 取込前プレビューの必要性を説明できる

## 8. 学習観点

- ファイル取込は入力検証が重要
- 全件失敗と一部失敗を分ける
- 業務利用者が直せるエラーにする
