# web05_responsive_layout 要件定義

## 1. 目的
カード一覧レイアウトを作りながら、CSS Grid / Flexbox / レスポンシブ対応の基礎を理解する。

## 2. 対象ユーザー

- 画面幅に応じてレイアウトを変える方法を学びたい人
- 一覧画面やカードUIの基本を身につけたい人
- CSS Grid と Flexbox の使い分けを体験したい人

## 3. 作成する成果物

複数のカードを並べるレスポンシブな静的ページを作成する。
想定ファイル構成:

```text
src/frontend/src/studyweb/systems/web05_responsive_layout/
  index.html
  styles.css
```

学習手順は `doc/learning_notes/web05_responsive_layout/README.md` に配置する。

## 4. 機能要件

### 4.1 ページ表示

- ヘッダー、カード一覧、フッターを表示すること
- カードにはタイトル、説明文、カテゴリ、ボタンを含めること
- カードを少なくとも数件表示すること

### 4.2 レイアウト
- PC幅ではカードを複数列で表示すること
- スマートフォン幅ではカードを1列で表示すること
- Grid または Flexbox を使ってカードを配置すること
- 余白、行間、カード幅が画面幅に応じて破綻しないこと

### 4.3 レスポンシブ確認
- メディアクエリを使って表示を切り替えること
- DevTools のデバイスモードでスマートフォン幅を確認できること

## 5. 非機能要件

- 外部CSSフレームワークは使わないこと
- JavaScript は必須にしないこと
- 横スクロールが発生しないこと
- 文字がカード外にはみ出さないこと

## 6. 学習ポイント
- Grid / Flexbox による一覧配置
- `gap`、`max-width`、`margin`、`padding` の使い方
- メディアクエリによる画面幅に応じた調整
- カードUIが多くの業務画面の基本単位になること

## 7. 完了条件

- PC幅でカードが複数列表示される
- スマートフォン幅でカードが1列表示される
- 横スクロールが発生しない
- README に確認手順・学習ポイントが書かれている

## 8. 対象外

- TypeScript

- データベース
