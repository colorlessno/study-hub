# web30_error_log_note 要件定義

## 1. 目的

学習中に発生したエラー内容、原因、解決方法を記録するテンプレートを作り、同じ問題で詰まる時間を減らす。

## 2. 対象ユーザー

- エラー解決の記録を残したい人
- 学習効率を上げたい人
- 後から見返せるトラブルシュート集を作りたい人

## 3. 作成する成果物

エラー記録用の Markdown テンプレートを作成する。

想定ファイル構成:

```text
doc/learning_notes/web30_error_log_note/
  README.md
  examples/
    css-not-loaded.md
    api-404.md
doc/templates/web30_error_log_note/
  error-log-template.md
```

## 4. 機能要件

### 4.1 記録項目

- 発生日時を記録できること
- エラー内容を記録できること
- 再現手順を記録できること
- 原因を記録できること
- 解決方法を記録できること
- 次回確認するポイントを記録できること

### 4.2 記入例

- CSS が読み込まれない例を用意すること
- API 404 の例を用意すること
- 初学者が真似しやすい粒度にすること

### 4.3 検索性

- タグやカテゴリを記録できること
- エラー種別を後から探しやすくすること

## 5. 非機能要件

- Markdown で作成すること
- エラーメッセージはコードブロックで記録すること
- 個人情報や秘密情報を貼らない注意を入れること
- 記録が重荷にならない分量にすること

## 6. 学習ポイント

- エラーを再現可能な形で記録すること
- 原因と対処を分けて考えること
- 解決済みの知識を資産化すること
- DevTools やログの見方を残すこと

## 7. 完了条件

- エラー記録テンプレートがある
- 記入例が2件以上ある
- README に使い方が書かれている
- 秘密情報を記録しない注意が書かれている

## 8. 対象外

- ログ収集システム
- 監視基盤
- 自動エラー解析
- チケット管理ツール連携
- 本格的なナレッジベース
