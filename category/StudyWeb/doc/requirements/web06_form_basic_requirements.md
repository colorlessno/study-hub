# web06_form_basic 要件定義

## 1. 目的
入力フォームと基本的なバリデーションを作り、Webアプリにおける入力・確認・送信の流れを理解する。

## 2. 対象ユーザー

- フォーム要素の使い方を学びたい人
- 入力チェックの基本を理解したい人
- ログイン、検索、問い合わせなどの土台を作りたい人

## 3. 作成する成果物

問い合わせフォーム風の静的Webページを作成する。
想定ファイル構成:

```text
src/frontend/src/studyweb/systems/web06_form_basic/
  index.html
  styles.css
  script.js
```

学習手順は `doc/learning_notes/web06_form_basic/README.md` に配置する。

## 4. 機能要件

### 4.1 フォーム表示

- 名前、メールアドレス、問い合わせ種別、本文の入力欄を表示すること
- 送信ボタンとリセットボタンを表示すること
- 必須項目がわかる表示にすること

### 4.2 入力チェック

- 必須項目が空の場合はエラーメッセージを表示すること
- メールアドレスの形式が不正な場合はエラーメッセージを表示すること
- エラーがなければ送信成功メッセージを表示すること

### 4.3 操作
- 送信時にページ遷移せず JavaScript で結果を表示すること
- リセットボタンで入力内容とメッセージを初期化できること

## 5. 非機能要件

- 外部フレームワークは使わないこと
- HTML の標準フォーム要素を使うこと
- エラーメッセージは入力欄の近くに表示すること
- スマートフォン幅でも操作しやすいこと

## 6. 学習ポイント
- `form`、`input`、`select`、`textarea` の基本
- `submit` イベントと `preventDefault`
- 入力値の取得と検証
- ユーザーにわかりやすいエラー表示

## 7. 完了条件

- 必須項目の未入力を検出できる
- 不正なメールアドレスを検出できる
- 正常入力時に成功メッセージが表示される
- README に入力チェック内容と確認手順が書かれている

## 8. 対象外
- 実際のメール送信
- API 通信
- データベース保存
- 認証
- React
