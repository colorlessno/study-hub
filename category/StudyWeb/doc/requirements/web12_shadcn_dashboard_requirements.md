# web12_shadcn_dashboard 要件定義

## 1. 目的
shadcn/ui 風の管理画面を作り、業務画面や SaaS 画面に近いUI構成を理解する。

## 2. 対象ユーザー

- 管理画面のレイアウトを学びたい人
- コンポーネントライブラリを使ったUI構築を体験したい人
- ダッシュボードの基本要素を整理したい人

## 3. 作成する成果物

サイドバー、ヘッダー、指標カード、テーブルを持つダッシュボード画面を作成する。
想定ファイル構成:

```text
src/frontend/src/studyweb/systems/web12_shadcn_dashboard/
  package.json
  src/
    components/
      AppSidebar.tsx
      Header.tsx
      StatCard.tsx
      DataTable.tsx
    App.tsx
    main.tsx
```

学習手順は `doc/learning_notes/web12_shadcn_dashboard/README.md` に配置する。

## 4. 機能要件

### 4.1 ダッシュボード表示

- サイドバーを表示すること
- ヘッダーを表示すること
- 指標カードを複数表示すること
- データ一覧テーブルを表示すること

### 4.2 UI部品
- Button、Card、Table などの再利用可能なUI部品を使うこと
- Tailwind CSS と組み合わせて見た目を調整すること
- アイコンを使用する場合は lucide-react などの一般的なライブラリを使うこと

### 4.3 レスポンシブ
- スマートフォン幅でも主要情報が読めること
- サイドバーは幅に応じて折りたたみまたは縦並びにできること

## 5. 非機能要件

- Vite + React + TypeScript を使うこと
- shadcn/ui の考え方に沿った部品構成にすること
- 管理画面らしく、情報密度と読みやすさを優先すること
- 過度な装飾やランディングページ風の構成にしないこと

## 6. 学習ポイント
- 管理画面の基本構成
- UIコンポーネントの再利用
- Tailwind とコンポーネント設計の組み合わせ
- 一覧、指標、ナビゲーションの配置

## 7. 完了条件

- ダッシュボード画面が表示される
- 指標カードとテーブルが表示される
- レスポンシブ表示が破綻しない
- README に使用コンポーネントと起動方法が書かれている

## 8. 対象外
- 実データのAPI取得
- 認証
- 権限管理
- 本格的なデザインシステム構築範囲
- グラフライブラリの高度利用
