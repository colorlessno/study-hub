# web29_readme_template 要件定義

## 1. 目的

作成した成果物を説明できる README テンプレートを作り、目的、使い方、構成、学習ポイントを整理する習慣を身につける。

## 2. 対象ユーザー

- 作ったサンプルを他人に説明できる形にしたい人
- GitHub に学習成果を置きたい人
- ポートフォリオ化の入口を作りたい人

## 3. 作成する成果物

Web開発サンプル用の README テンプレートを作成する。

想定ファイル構成:

```text
doc/learning_notes/web29_readme_template/
  README.md
doc/templates/web29_readme_template/
  README.template.md
  README.example.md
```

## 4. 機能要件

### 4.1 README項目

- 概要を記載できること
- 使用技術を記載できること
- 起動方法を記載できること
- 画面やAPIの確認方法を記載できること
- 学習ポイントを記載できること

### 4.2 記録項目

- 詰まった点を記録できること
- 解決方法を記録できること
- 今後の改善案を記録できること

### 4.3 利用しやすさ

- コピペして各サンプルに流用できること
- 記入例を含めること

## 5. 非機能要件

- Markdown で作成すること
- 見出し構造が分かりやすいこと
- 長すぎず、学習成果として読みやすいこと
- コマンドはコードブロックで書くこと

## 6. 学習ポイント

- README の役割
- 成果物の説明方法
- 起動手順の明文化
- 学習ログと改善案の残し方

## 7. 完了条件

- README テンプレートがある
- 記入例がある
- Webサンプルへ流用できる
- README に使い方が書かれている

## 8. 対象外

- 自動ドキュメント生成
- API仕様書の詳細
- 画像付きの高度なポートフォリオページ
- GitHub Actions
- ライセンス文書の詳細
