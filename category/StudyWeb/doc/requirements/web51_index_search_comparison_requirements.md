# web51 indexあり/なし検索比較 要件定義

## 1. 目的

DB index の有無で検索性能が変わることを体験し、検索条件とindex設計の基本を理解する。

## 2. 学習対象

- DB index
- search condition
- explain
- response time
- pagination
- query plan basics

## 3. 作成する成果物

- 検索用テーブル
- indexなし検索
- indexあり検索
- 実行時間比較
- explain確認メモ

## 4. 機能要件

| ID | 要件 |
|---|---|
| FR-01 | 検索対象データを用意できる |
| FR-02 | indexなし検索を実行できる |
| FR-03 | indexあり検索を実行できる |
| FR-04 | 実行時間または実行計画を比較できる |
| FR-05 | 検索条件とindexの関係を説明できる |

## 5. 非機能要件

| ID | 要件 |
|---|---|
| NFR-01 | 学習用データ量で差が見えるようにする |
| NFR-02 | DBに過度な負荷をかけない |
| NFR-03 | indexを増やせば常に良い、という説明にしない |

## 6. 対象外

- 高度なDBチューニング
- 複合indexの深掘り
- 本番DB運用

## 7. 受入条件

- indexあり/なしの違いを確認できる
- 検索条件に合うindexの考え方を説明できる
- indexのデメリットも説明できる

## 8. 学習観点

- 遅い検索は設計とデータ量に依存する
- indexは読み取りを助けるが更新コストもある
- explainは性能調査の入口になる
