# web52 要件定義

## 目的

利用場面の条件からWeb画面の表示方式を選び、選定理由、処理の役割分担、キャッシュする範囲、不採用案、運用上の注意点を説明できるようにする。

## 利用者が行うこと

- 用意された4つの利用場面から比較対象を選ぶ
- MPA、SPA、SSR、SSGから基本となる方式を選ぶ
- Server Components、Islands、PWAを必要に応じて組み合わせる
- 判断メモを入力し、ブラウザ内に保存する
- 利用場面を切り替え、保存した判断メモを比較する
- 現在の利用場面について保存したメモを削除する

## 画面に表示する内容

| 内容 | 表示する情報 |
|---|---|
| 利用場面 | 名称、認証、更新頻度、検索結果への掲載、画面操作、通信条件等 |
| 表示方式 | MPA、SPA、SSR、SSGと短い説明 |
| 組み合わせる仕組み | Server Components、Islands、PWAと短い説明 |
| 判断メモ | 選定理由、役割分担、キャッシュ範囲、不採用案、運用上の注意点 |
| 保存状態 | 保存済みの利用場面数、現在の利用場面の保存内容 |

## 入力と保存

- 基本となる表示方式と選定理由は必須とする
- 利用場面ごとに1件の判断メモを保存する
- 保存先はブラウザの `localStorage` とする
- 入力内容はサーバーへ送信しない
- ファイルの作成や書き換えは行わない

## 対象外

- 各方式の性能測定
- 特定フレームワークを使った実装
- サーバーやデータベースへの判断メモ保存
- StudyHub内での教材文書編集

## 確認できる状態

- 4つの利用場面を切り替えられる
- 必須入力がないときは保存せず、必要な入力を示す
- 保存後に別の利用場面へ移動し、戻ると保存内容が復元される
- 現在の利用場面のメモだけを削除できる
- 画面、README、学習項目、ソース、設計文書の内容が一致している
