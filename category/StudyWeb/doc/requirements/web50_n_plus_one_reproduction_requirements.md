# web50 N+1問題の再現 要件定義

## 1. 目的

ORM利用時に発生しやすい N+1 問題を再現し、クエリ回数と性能劣化の原因を理解する。

## 2. 学習対象

- N+1 query
- relation loading
- eager loading
- query log
- performance comparison

## 3. 作成する成果物

- N+1再現データ
- 悪い取得例
- 改善した取得例
- クエリログ比較
- 計測メモ

## 4. 機能要件

| ID | 要件 |
|---|---|
| FR-01 | 親子データを用意できる |
| FR-02 | N+1が発生する取得を再現できる |
| FR-03 | クエリ回数を確認できる |
| FR-04 | eager loading 等で改善できる |
| FR-05 | 改善前後の差を記録できる |

## 5. 非機能要件

| ID | 要件 |
|---|---|
| NFR-01 | 小さいデータでも問題構造が分かる |
| NFR-02 | DBログまたはアプリログで確認できる |
| NFR-03 | 高度なチューニングに踏み込みすぎない |

## 6. 対象外

- DB index詳細
- 大規模負荷試験
- クエリプラン深掘り

## 7. 受入条件

- N+1がなぜ起きるか説明できる
- 改善前後のクエリ回数を比較できる
- ORM利用時の注意点を説明できる

## 8. 学習観点

- ORMはSQLを隠すが、SQLは実行されている
- 一覧画面では関連データ取得に注意する
- 性能問題はログで確認する
