# web01_static_first_page 要件定義

## 1. 目的
HTML / CSS / JavaScript の役割分担を、最小の自己紹介ページを作りながら理解する。
このサンプルでは、次の3点を体験できることを目的とする。

- HTML はページの構造を担当する
- CSS はページの見た目を担当する
- JavaScript はページの動きを担当する

## 2. 対象ユーザー

- Web開発を初めて学ぶ学習者
- HTML / CSS / JavaScript の違いをまだ実感できていない人
- ブラウザで静的ページを表示する流れを確認したい人

## 3. 作成する成果物

自己紹介ページを1つ作成する。
想定ファイル構成:

```text
src/frontend/src/studyweb/systems/web01_static_first_page/
  index.html
  styles.css
  script.js

doc/learning_notes/web01_static_first_page/
  README.md
```

## 4. 機能要件

### 4.1 ページ表示

- ブラウザで `index.html` を開くと自己紹介ページが表示されること
- ページタイトルが表示されること
- 名前またはニックネームが表示されること
- 短い自己紹介文が表示されること
- 好きなもの、学習中のこと、目標などを箇条書きで表示できること

### 4.2 見た目

- CSS ファイルを使って見た目を調整すること
- HTML に直接大量のスタイルを書かないこと
- 以下のいずれかを CSS で持つこと
  - 文字色
  - 背景色
  - 余白
  - 枠線
  - カード風の見た目

### 4.3 動き

- JavaScript ファイルを読み込むこと
- ボタンをクリックすると画面の表示が変わること
- 例
  - あいさつ文字を表示する
  - 自己紹介文を切り替える
  - 現在時刻を表示する

## 5. 非機能要件

- 外部フレームワークは使わないこと
- ビルドツールは使わないこと
- インターネット接続なしでも表示できること
- 主要な学習対象は HTML / CSS / JavaScript の3ファイルに絞られていること
- 初学者がファイルを開いて読み切れるコード量にすること

## 6. 学習ポイント
- `index.html` がブラウザに読み込まれる流れ
- `<link>` による CSS ファイルの読み込み
- `<script>` による JavaScript ファイルの読み込み
- HTML の要素と CSS セレクタの関係
- JavaScript から HTML 要素を取得して表示を変える流れ

## 7. 完了条件

- `index.html` をブラウザで開くと自己紹介ページが表示される
- CSS による見た目の変更が反映されている
- JavaScript によるクリック操作が動作する
- README に目的・起動方法・学習ポイントが書かれている

## 8. 対象外
- React / Vue などのフロントエンドフレームワーク
- TypeScript
- API 通信
- データベース
- Docker
- 認証機能
