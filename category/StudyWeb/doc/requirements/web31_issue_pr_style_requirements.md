# web31_issue_pr_style 要件定義

## 1. 目的

Issue / PR 風の作業記録テンプレートを作り、作業内容、修正理由、影響範囲、確認結果を説明する練習をする。

## 2. 対象ユーザー

- 実務に近い作業説明を練習したい人
- GitHub Issue / Pull Request の書き方を学びたい人
- 就活やポートフォリオで変更内容を説明できるようにしたい人

## 3. 作成する成果物

Issue と PR の記録テンプレートを作成する。

想定ファイル構成:

```text
doc/templates/web31_issue_pr_style/
  issue-template.md
  pr-template.md
doc/learning_notes/web31_issue_pr_style/
  README.md
  gitea-practice-entry.md
  examples/
    sample-issue.md
    sample-pr.md
```

## 4. 機能要件

### 4.1 Issue テンプレート

- 背景を記録できること
- 目的を記録できること
- やることをチェックリストで記録できること
- 完了条件を記録できること

### 4.2 PR テンプレート

- 変更概要を記録できること
- 変更理由を記録できること
- 影響範囲を記録できること
- 動作確認結果を記録できること
- 未対応事項を記録できること

### 4.3 記入例

- Webサンプル作成を題材にした Issue 例を用意すること
- 小さな修正を題材にした PR 例を用意すること

## 5. 非機能要件

- Markdown で作成すること
- 実務で読みやすい簡潔な文量にすること
- チェックリストを使うこと
- コード変更がなくても作業記録として使えること

## 6. 学習ポイント

- 作業の背景と目的を分けて書くこと
- 変更内容と変更理由を分けて書くこと
- 影響範囲を意識すること
- 確認結果を残すこと

## 7. 完了条件

- Issue テンプレートがある
- PR テンプレートがある
- 記入例がある
- README に使い方と記入時の注意が書かれている
- StudyHubからひな形、記入例、Gitea演習案内を読み取り専用で確認できる

## 8. 対象外

- GitHub Actions
- 自動レビュー
- ブランチ運用ルールの詳細
- チーム開発規約の本格策定
- プロジェクト管理ツール連携
