# web40 テーブル検索・ページ分割 要件定義

## 目的

業務で使う一覧画面を小さなローカルデータで再現し、検索、絞り込み、並べ替え、ページ分割、表示状態の違いを実際に操作できるようにします。

## 利用者が行うこと

- 17件のデータを5件単位で確認する
- 名前の部分一致で検索する
- 対応中または完了で絞り込む
- 名前の昇順と降順を切り替える
- 前後のページへ移動する
- 読込中、通常表示、検索結果なし、読込エラーを切り替えて比較する

## 一覧画面に必要な動作

| 操作または状態 | 必要な動作 |
|---|---|
| 初期表示 | 17件中の1〜5件と、4ページ中1ページ目を表示する |
| 名前検索 | 大文字と小文字を区別せず、名前の部分一致で絞り込む |
| 対応状況 | 対応中または完了だけに絞り込む |
| 名前順 | 昇順と降順を切り替える |
| ページ移動 | 1ページ5件で、存在するページの範囲内だけ移動する |
| 検索結果なし | 正常に検索した結果が0件であることを表示する |
| 読込中 | データを処理していることを表示し、ページ移動を無効にする |
| 読込エラー | 処理に失敗したことと通常表示へ戻す方法を表示する |

## 画面で守ること

- 入力欄と選択欄にラベルを付ける
- 表に列見出しを付ける
- 最初と最後のページでは、進めない方向のボタンを無効にする
- 件数、表示範囲、現在ページ、総ページ数を表示する
- 長い名前でも表の外へはみ出さない
- キーボードで入力、選択、ボタン操作を行える

## 対象外

- APIやデータベースからの取得
- 大量データ向けの性能最適化
- 仮想スクロール
- サーバー側での検索やページ分割

## 完成した状態

- 検索、絞り込み、並べ替え、ページ移動を組み合わせても範囲外ページを表示しない
- 読込中、通常表示、検索結果なし、読込エラーを画面上で区別できる
- READMEの操作手順、学習項目、画面のラベル、実装内容が一致している
