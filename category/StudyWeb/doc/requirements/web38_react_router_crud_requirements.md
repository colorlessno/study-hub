# web38 React Router CRUD 要件定義

## 1. 目的

一覧、詳細、新規作成、編集の画面遷移を React Router で実装し、業務CRUDの基本導線を理解する。

## 2. 学習対象

- React Router
- route params
- list / detail / create / edit
- navigation
- not found

## 3. 作成する成果物

- CRUD画面一式
- ルーティング定義
- 画面遷移確認手順
- not found 画面

## 4. 機能要件

| ID | 要件 |
|---|---|
| FR-01 | 一覧画面を表示できる |
| FR-02 | 詳細画面へ遷移できる |
| FR-03 | 新規作成画面へ遷移できる |
| FR-04 | 編集画面へ遷移できる |
| FR-05 | 存在しないIDでnot foundを表示できる |

## 5. 非機能要件

| ID | 要件 |
|---|---|
| NFR-01 | URLと画面状態が対応する |
| NFR-02 | 戻る・進む操作を考慮する |
| NFR-03 | 学習用のローカルデータで完結できる |

## 6. 対象外

- DB連携
- 認証認可
- 複雑な状態管理

## 7. 受入条件

- URLから画面を説明できる
- 一覧、詳細、作成、編集の導線を確認できる
- 不正なIDの扱いを確認できる

## 8. 学習観点

- 業務CRUDは画面遷移が重要
- IDをURLで扱う
- not found は正常な異常系である
