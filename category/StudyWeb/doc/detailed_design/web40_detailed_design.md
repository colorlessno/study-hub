## データ

| 項目 | 型 | 内容 |
|---|---|---|
| `id` | number | 1〜17 |
| `name` | string | `Item A0`等の表示名 |
| `status` | string | `open` / `closed` |

データはJavaScriptで生成し、API・DBは使用しない。

## 画面で保持する状態

| 状態 | 内容 |
|---|---|
| `keyword.value` | 名前検索に使う文字列 |
| `status.value` | すべて、対応中、完了 |
| `currentPage` | 0から始まる現在ページ |
| `ascending` | 名前の昇順または降順 |
| `displayState.value` | 通常表示、読込中、読込エラー |
| `PAGE_SIZE` | 1ページ5件で固定 |

## 一覧計算

`table-state.js`の`buildTableState`が、画面表示に必要な値をまとめて返します。

1. 検索語を前後の空白を除いた小文字へ変換する。
2. 名前の部分一致で絞り込む。
3. 対応状況が「すべて」でなければ、対応中または完了で絞り込む。
4. 名前の昇順または降順で並べ替える。
5. 絞り込み後の件数から総ページ数を計算する。
6. 現在ページを0以上かつ最終ページ以下へ補正する。
7. 現在ページに表示する最大5件を取り出す。
8. 表示範囲と前後移動の可否を返す。

## 操作

| 操作 | 状態変更 |
|---|---|
| 名前入力 | `currentPage = 0`として再表示 |
| 対応状況の変更 | `currentPage = 0`として再表示 |
| 名前順 | `ascending`を反転し、`currentPage = 0`として再表示 |
| 前のページ | `currentPage`を1減らして再表示。計算時に下限を補正 |
| 次のページ | `currentPage`を1増やして再表示。計算時に上限を補正 |
| 表示状態の変更 | 通常表示、読込中、読込エラーを切り替える |

## 表示状態ごとの描画

| 状態 | 件数表示 | 表の内容 | ページボタン |
|---|---|---|---|
| 通常表示 | 件数、表示範囲、総ページ数、現在ページ | 最大5件 | 境界に応じて有効または無効 |
| 検索結果なし | 0件、0ページ | 検索結果なしの文 | 両方無効 |
| 読込中 | 読込中の文 | 読込中の文 | 両方無効 |
| 読込エラー | 読込失敗の文 | エラーと戻し方の文 | 両方無効 |

## 確認手順

1. 初期17件が5件単位の4ページになることを確認する。
2. 1ページ目では前、4ページ目では次のボタンが無効になることを確認する。
3. 名前検索、対応状況、名前順を組み合わせ、条件変更後に1ページ目へ戻ることを確認する。
4. 一致しない名前で検索結果なしを確認する。
5. 読込中と読込エラーを選び、検索結果なしとは異なる表示になることを確認する。
6. 通常表示へ戻し、一覧操作を再開できることを確認する。

## 実装上の範囲

- ローカル17件をブラウザ内で処理し、APIとデータベースは使用しません。
- 並べ替え対象は名前だけです。
- サーバー側の検索、並べ替え、ページ分割は扱いません。
