# 再試行の判断基準

| 失敗 | 例 | 再試行の判断 |
|---|---|---|
| 時間切れ | 一時的な遅延、通信の不調 | 条件付きで再試行する |
| 429 | 呼び出し回数の上限 | 指定された待ち時間に従う |
| 503 | 一時的な利用不可 | 再試行の候補にする |
| 400 | 入力内容の誤り | 入力を直さず再試行しない |
| 401 / 403 | 認証または権限の不足 | 条件を直さず再試行しない |
| 404 | 対象が存在しない | 通常は再試行しない |

## この教材の設定

- 最大試行回数は3回
- 1回ごとに100ミリ秒待つ
- 状態番号503だけを再試行する
- すべての試行結果を画面へ残す

回数だけでなく、1回ごとの制限時間と全体の処理時間にも上限を設けます。登録や更新のように結果を変更する操作では、再試行前に重複実行を防げるか確認します。
