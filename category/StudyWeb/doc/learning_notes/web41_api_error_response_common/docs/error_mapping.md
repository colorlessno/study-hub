# エラー種別と表示先

| 種別 | 画面上の表示先 |
|---|---|
| 入力エラー | 対応する入力項目の近く |
| 業務エラー | フォームまたは画面の上部 |
| 内部エラー | 共通の通知欄 |

HTTP状態コードだけで表示先を決めず、安定したエラーコードと詳細情報を使って判断します。

StudyHubの実行欄はこの表のフロント接続例です。入力エラーでは`details[].field`と`details[].message`を項目別表示へ変換し、業務エラーと内部エラーでは`code`に対応する表示先と利用者向け`message`を表示します。生のJSONも残すため、変換前後を同じ画面で比較できます。
