# web05 レスポンシブデザイン

CSS Grid、Flexbox、メディアクエリを組み合わせ、画面幅に応じて列数が変わる一覧を学ぶテーマです。

## このテーマでできるようになること

- ブラウザ幅をPC・タブレット・スマートフォン相当に変え、カードの列数が変わることを確認できる
- CSS Gridがカード全体の配置、Flexboxがカード内の部品配置を担当していることを確認できる
- 画面幅を狭くしても横スクロールが発生しないことを確認できる

## 最初に取り組むこと

次の順番で確認する。

1. `index.html`を開き、DevToolsのデバイスモードで821px、820px、561px、560pxの表示を比較する。
2. 列数が変わる幅とCSSのメディアクエリを照合する。
3. ページ全体の列配置にGrid、カード内部の配置にFlexboxを使う箇所を確認する。
4. `minmax(0, 1fr)`とカード内の指定を確認し、長い内容によるはみ出しとボタン位置のずれを防ぐ仕組みを確認する。

## 起動方法

実装ディレクトリの`index.html`をブラウザで開きます。JavaScriptとビルド処理は使用しません。

## 観察ポイント

| 画面幅 | 期待する列数 |
|---:|---:|
| 821px以上 | 3列 |
| 561px〜820px | 2列 |
| 560px以下 | 1列 |

- すべてのカード幅が均等か
- 説明の長さが違ってもボタン位置が揃うか
- 560px以下でbodyの余白も縮むか
- どの幅でも横スクロールが発生しないか

## 自分の言葉で説明する

- 一覧にはGrid、カード内部にはFlexboxを使う理由は何ですか。
- 820pxと560pxの境界をどのように検証しましたか。
- 横スクロールを防ぐために使っている指定を3つ挙げてください。

## うまく動かないとき

- 列数が変わらない場合は、viewport設定と適用中のメディアクエリを確認します。
- 横にはみ出す場合は、幅が固定された要素、長い文字列、`min-width`を確認します。
- ボタン位置が揃わない場合は、カードのFlexboxと`margin-top: auto`を確認します。
