# フォーム状態の流れ

```text
入力中
  ├─ 不正な入力 -> 項目別エラー -> 入力中
  └─ 正常な入力 -> 内容確認
                     ├─ 入力を修正 -> 入力中
                     └─ 送信 -> 送信中
                                  ├─ 成功 -> 次の入力
                                  └─ フォーム全体エラー -> 入力中または再試行
```

項目別エラーでは最初の修正対象へフォーカスを移す。確認画面では値を送信前に見直し、入力へ戻って修正できる。送信中は同じ操作を繰り返せないよう、送信と修正の両ボタンを無効にする。送信失敗時は入力値を保持してフォーム全体エラーを表示する。
