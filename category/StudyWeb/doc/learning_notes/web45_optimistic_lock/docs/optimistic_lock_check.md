# 楽観ロックの確認手順

| 操作 | 期待する結果 |
|---|---|
| 読込前に保存 | 読込が必要であることを表示する |
| AとBが同じ版を読込 | 両方が同じ読込内容を保持する |
| Aを先に保存 | 成功し、現在の版が1増える |
| 古いBを保存 | 競合し、現在のレコードを変更しない |
| Bを再読込して保存 | 最新の版なので成功する |
| 保存済みの古いAを再保存 | 更新競合になる |

## 確認する不変条件

- version一致時だけ更新できる
- 成功するたびにversionが1増える
- 競合時はnameもversionも変更しない
- 競合した利用者へcurrent / yoursを示す

現在の更新競合は画面に表示する文字列であり、HTTP応答ではない。API版では版を条件にした更新が0件だった場合にHTTP 409と安定したエラー応答を返す。
