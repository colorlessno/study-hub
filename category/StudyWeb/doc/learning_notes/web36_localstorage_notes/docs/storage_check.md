# localStorageの確認手順

1. localStorage欄へ架空の学習メモを入力して「保存」を押す。
2. Application（保存領域）で`studyweb.web36.memo`の値を確認する。
3. 教材を再読み込みし、「読込」で同じ値が表示されることを確認する。
4. sessionStorage欄へ別の架空メモを保存し、同じタブの再読み込み後も残ることを確認する。
5. 同じURLを新しいタブで開き、`studyweb.web36.sessionMemo`が引き継がれないことを確認する。
6. 二つの「削除」を順番に押し、それぞれ対象のキーだけがなくなることを確認する。

実在するパスワード・認証情報・個人情報は入力しない。
