# Gitea演習への進み方

web31ではIssueとPRに書く内容を整理します。Issueの作成からブランチ、プッシュ、PR、レビュー、マージ、ローカルmainの同期までを実際に操作する場合は、StudyHubのbase08を使用します。

## StudyHubで開くテーマ

- 分野: IT基礎
- テーマ番号: base08
- テーマ名: Issue・branch・push・PR・merge・ローカル同期

## 役割分担

| テーマ | 行うこと |
|---|---|
| web31 | IssueとPRのひな形・記入例を確認し、説明文を作成する |
| base08 | Giteaを使い、Issueからローカルmainの同期までを実際に操作する |

StudyHubのテーマ一覧で`base08`を検索し、base08の画面にある手順と操作を使用します。実GitHubへ公開する操作は、公開対象と権限を確認した別工程として扱います。
