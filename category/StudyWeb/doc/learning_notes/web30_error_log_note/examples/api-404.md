# API 404

## 基本情報

- 発生日: 2026-04-28
- サンプル名: web21_network_debug
- 環境: Docker Compose
- 関連ファイル: `frontend/src/App.tsx`, `backend/src/debug.controller.ts`
- タグ: `api`, `404`, `network`

## 発生した現象

- 実際の動作: 画面からAPIを呼び出すと404が返った。
- 期待していた動作: APIからデバッグ用の応答が返る。

## エラー原文

```text
GET http://localhost:13021/debug/missing 404 (Not Found)
```

## 再現手順
1. Web画面を開く
2. 存在しないAPIパスを呼ぶ
3. ブラウザ開発者ツールの「Network（通信）」タブで404を確認する

## 調査中の予想

- APIが起動していない。
- フロントエンドの要求先とAPIの経路が一致していない。

## 確認した事実

- APIは起動しており、別の経路には応答した。
- フロントエンドは`/debug/missing`を要求していたが、APIにはその経路がなかった。

## 原因

フロントエンドが呼んでいるURLと、バックエンドに実装されている経路が一致していなかった。
## 対応内容
フロントエンドのURLを、実装済みの`/debug/not-found`に合わせた。

## 対応結果

同じ画面操作を行い、APIから想定した応答が返ることを確認した。

## 次回の確認箇所

- API一覧とフロントの呼び出し元が一致しているか
- 404はネットワーク断ではなくルーティング不一致でも発生する
