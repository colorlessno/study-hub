# CSSが読み込まれない

## 基本情報

- 発生日: 2026-04-28
- サンプル名: web03_file_path_assets
- 環境: ローカルブラウザ
- 関連ファイル: `index.html`, `styles/style.css`
- タグ: `css`, `path`, `devtools`

## 発生した現象

- 実際の動作: 自己紹介ページの装飾が適用されず、文字だけで表示された。
- 期待していた動作: `styles/style.css`の装飾が適用された状態で表示される。

## エラー原文

```text
GET file:///.../style.css net::ERR_FILE_NOT_FOUND
```

## 再現手順

1. `index.html`を開く
2. ブラウザ開発者ツールの「Network（通信）」タブを開く
3. CSSのステータスが失敗していることを確認する

## 調査中の予想

- HTMLに書いたCSSのファイルパスが実際の配置と違っている。
- CSSファイルが保存されていない。

## 確認した事実

- `styles/style.css`は存在していた。
- HTMLは`style.css`を要求し、通信一覧では読み込みに失敗していた。

## 原因

HTMLでは`style.css`を参照していたが、実際のファイルは`styles/style.css`に配置されていた。

## 対応内容

`index.html`の参照を`./styles/style.css`に修正した。

## 対応結果

ページを再読み込みし、CSSの装飾が適用され、通信一覧の読み込みが成功したことを確認した。

## 次回の確認箇所

- HTMLから見た相対パスになっているか
- 通信一覧で404や読み込み失敗を確認する
