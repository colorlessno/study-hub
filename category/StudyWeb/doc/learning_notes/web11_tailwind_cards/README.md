# web11 Tailwind CSSのカード画面

Tailwind CSSのクラスを組み合わせ、画面幅に応じて列数と見た目が変わるカード一覧を確認するテーマです。

## このテーマでできるようになること

- 画面幅を変えると、カードが1列・2列・4列へ切り替わることを確認できる
- カードにカーソルを合わせると、位置・枠線・影が変化することを確認できる
- 余白・色・枠線・影がTailwind CSSのクラスで指定されていることを確認できる
- 各カードの「表示例」を押し、選択したカード名が結果へ表示されることを確認できる

## 最初に取り組むこと

次の順番で確認する。

1. 画面を起動し、横幅を狭い状態、中間、広い状態へ変えて列数を確認する。
2. カードにカーソルを合わせ、位置、枠線、影の変化を確認する。
3. `App.tsx`のカード一覧で、画面幅、余白、色、枠線、影を指定するクラスを探す。
4. 各カードの「表示例」を押し、選択結果と`selectedTitle`の更新を対応させる。
5. Tailwind CSSのクラスと、画面に反映される見た目を1つずつ対応させる。

## 起動方法

StudyHubのテーマ画面で「起動」を押します。手動で確認する場合は、実装ディレクトリで`npm ci`を実行してから`npm run dev`を実行します。

## 観察ポイント

- 狭い幅では1列、`md`以上では2列、`lg`以上では4列になるか
- `hover:`から始まるクラスが、カーソルを合わせたときだけ反映されるか
- `p-5`、`border`、`shadow-sm`が余白、枠線、影へ反映されるか
- 各カードの高さと下端の表示例ラベルの位置が揃っているか
- 「表示例」を押したカード名が結果へ表示されるか

## 自分の言葉で説明する

- 画面幅ごとの列数を1つのclassNameへまとめる方法
- 通常時とカーソルを合わせた状態の見た目を分ける方法
- Tailwind CSSのクラスを使う場合と、別のCSSファイルへ書く場合の違い
- ボタン操作で選択したカード名をstateへ保持する流れ

## うまく動かないとき

- クラスが反映されない場合は、`index.css`とTailwind設定の対象ファイルを確認します。
- 列数が変わらない場合は、`md:grid-cols-2`と`lg:grid-cols-4`を確認します。
- カーソルを合わせても変化しない場合は、`hover:`から始まるクラスを確認します。
- 選択結果が変わらない場合は、ボタンの`onClick`と`setSelectedTitle`を確認します。
