# web03 ファイルパス

2つのHTMLから同じCSS、JavaScript、画像を相対パスで参照し、ファイル階層とURLの関係を学ぶテーマです。

## このテーマでできるようになること

- 最初のページと補足ページの両方で、CSS・JavaScript・画像が表示されることを確認できる
- 各HTMLに書かれたCSS・JavaScript・画像のファイルパスを、実際のフォルダ構成と照合できる
- 各ページの確認ボタンを押し、現在表示しているHTMLのファイル名を確認できる
- ブラウザ開発者ツールのNetwork（通信）タブで、読み込まれたファイル名を確認できる

## 最初に取り組むこと

次の順番で確認する。

1. `index.html`と`about.html`を開き、両方でCSS、JavaScript、画像が読み込まれることを確認する。
2. 各HTMLの参照記述と実際のフォルダ構成を照合し、`./`が参照元ファイルのあるフォルダを指すことを確認する。
3. ボタンを押して、現在表示しているHTMLのファイル名が結果へ出ることを確認する。
4. 参照記述と実際のファイル名の大文字・小文字を照合し、Windowsでは見逃しやすいLinux上の不一致を確認する。
5. HTMLからCSS、JavaScript、画像へ向かう関係を図にする。

## 起動方法

`index.html`を直接開くか、実装ディレクトリで簡易HTTPサーバーを起動します。

```bash
python -m http.server 8003
```

ブラウザで`http://localhost:8003`を開きます。`file://`で出る拡張機能やブラウザ由来の警告と、サンプル自身のエラーを区別しやすいため、Network観察にはHTTPサーバーが向いています。

## 正しいパスの例

```html
<link rel="stylesheet" href="./styles/style.css">
<script src="./scripts/main.js" defer></script>
<img src="./images/avatar.svg" alt="アバター画像">
```

参照先を`./style.css`、`./main.js`、`./avatar.svg`とすると、実ファイルが各サブディレクトリにあるため404になります。

## 観察ポイント

- 2ページのCSSとJavaScriptのURLが同じか
- ページ遷移後にdocumentが変わり、共通のCSS、JavaScript、画像が再利用・再取得されるか
- ボタンの結果が現在のHTMLファイル名になるか
- 560px以下でカードが1列になるか
- ファイル名の大文字小文字が実ファイルと一致しているか

## 自分の言葉で説明する

- 相対パスの起点は何ですか。
- `./`と`../`の違いを、ディレクトリ図を使って説明してください。
- 2ページで同じCSSを共有する利点と注意点は何ですか。

## うまく動かないとき

- Networkの404 URLと実際のディレクトリ構成を1階層ずつ比較します。
- 片方のページだけ失敗する場合は、失敗したHTML内の参照を確認します。
- scriptは200なのに動かない場合は、Consoleとclass名を確認します。
