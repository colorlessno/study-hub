# ファイル検証の役割

このテーマは、ブラウザが取得できるファイル情報を使って、拡張子、種類、容量を確認します。

| 確認項目 | 現在の条件 | この条件だけでは判断できないこと |
|---|---|---|
| 拡張子 | ファイル名が`.pdf`で終わる | 名前は変更できるため、内容がPDFかは分からない |
| MIMEタイプ | 空でなければ`application/pdf`である | ブラウザから通知された値であり、内容の保証にはならない |
| 容量 | 1MiB以下である | 破損、暗号化、ページ数、内容の安全性は分からない |

## 画面内の確認データ

| ボタン | ファイル名 | 種類 | 容量 | 期待する判定 |
|---|---|---|---:|---|
| 小さいPDF | `sample-small.pdf` | `application/pdf` | 3,072バイト | 問題なし |
| PDF以外 | `sample-document.txt` | `text/plain` | 1,200バイト | 拡張子と種類の2件 |
| 容量超過PDF | `sample-large.pdf` | `application/pdf` | 1,048,577バイト | 容量の1件 |

確認データはファイル情報だけを再現します。PDF本体の構造を持つファイルではありません。

## 実際のアップロード機能で追加する確認

ブラウザ側の確認は、利用者へ早く問題を知らせ、不要な送信を減らすために使います。実際にファイルを受信するシステムでは、サーバー側で同じ条件を再検証し、PDFの識別情報、破損、暗号化、ウイルスなども用途に合わせて確認します。
