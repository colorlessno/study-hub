# ファイル情報の扱い

このテーマで表示する情報と、実際のアップロード機能で追加する情報を区別します。

| 情報 | 用途 | 現在の画面 |
|---|---|---|
| ファイル名 | 利用者が選んだファイルの識別 | 表示する |
| 容量 | 上限判定と容量表示 | 表示する |
| MIMEタイプ | 種類判定の補助 | 表示する |
| ハッシュ値 | 整合性確認と重複検出 | 扱わない |
| 保存先の識別子 | 保存したファイル本体の所在 | 扱わない |
| 処理状態 | 検査中、利用可能、失敗などの管理 | 扱わない |
| 登録日時・利用者 | 監査と管理 | 扱わない |

現在の画面はファイル本体を送信または保存しないため、保存先や処理状態も作りません。

実際のシステムでは、ファイル本体の保存場所と、検索や状態管理に使う情報の保存場所を分けることがあります。公開用URL、内部の保存先、利用者が付けた元のファイル名を同じ値として扱わないことが重要です。
