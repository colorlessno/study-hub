# web47 PDFファイル選択時の検証

ブラウザで選択したファイルについて、ファイル名の拡張子、ブラウザが通知した種類、容量を別々に確認するテーマです。ファイルの送信と保存は行いません。

## このテーマでできるようになること

- 小さいPDFのファイル名、容量、種類を確認できる
- PDF以外のファイルで、拡張子と種類の問題を確認できる
- 1MiBを超えるPDFで、容量の問題を確認できる
- 自分のPDFを選び、ブラウザが取得した情報を確認できる
- この画面がファイルを送信または保存しないことを確認できる
- ブラウザでの検証とサーバー側の検証の役割を区別できる

## 最初に取り組むこと

1. 「小さいPDF」を押し、検証結果が「問題なし」になることを確認する。
2. 「PDF以外」を押し、拡張子とファイルの種類に関する2件の問題を確認する。
3. 「容量超過PDF」を押し、1MiBを超えたことを示す問題を確認する。
4. 手元に確認用PDFがあれば「自分のファイルを確認」から選び、表示された情報を確認する。
5. 「結果をリセット」を押し、未選択の表示へ戻ることを確認する。

実データや機密文書は使わず、公開しても問題のない確認用ファイルだけを選びます。

## 画面の操作と確認する内容

| 操作 | 確認する内容 |
|---|---|
| 小さいPDF | `sample-small.pdf`、3KiB、`application/pdf`、問題なし |
| PDF以外 | `.pdf`ではない問題と、種類がPDFではない問題 |
| 容量超過PDF | 1MiBを1バイト超えたことによる問題 |
| 自分のファイルを選択 | ブラウザが取得したファイル名、容量、種類 |
| 結果をリセット | ファイル選択と検証結果が初期状態へ戻る |

用意された確認データは、画面の検証条件を毎回同じ内容で試すためのものです。ファイル本体を読み込んでPDFの内容を判定するものではありません。

## 実装を確認する

| ファイル | 役割 |
|---|---|
| `app/index.html` | 操作ボタン、ファイル選択、検証結果の表示 |
| `app/src/main.js` | 操作を受け取り、検証結果を画面へ反映 |
| `app/src/file-validation.js` | 拡張子、種類、容量の判定と確認データ |
| `app/src/style.css` | 画面の配置と判定状態の見た目 |

`accept="application/pdf"`はファイル選択画面の候補を絞る入力補助です。ファイルの安全性を保証する仕組みではありません。実際にファイルを受信するシステムでは、サーバー側でも種類、容量、内容などを再検証します。

## 自分の言葉で説明する

- 拡張子とMIMEタイプを別々に確認する理由
- ブラウザが通知した種類だけで安全と判断できない理由
- この画面でファイルの送信や保存が行われないと判断できる箇所
- 実際のアップロード機能でサーバー側の再検証が必要な理由

## うまく動かないとき

- 自分のファイルが選択画面に出ない場合は、ファイル形式の絞り込みがPDFになっているか確認する。
- 同じファイルを選び直して表示が変わらない場合は、「結果をリセット」を押してから選び直す。
- 用意された確認データで期待した問題が出ない場合は、`file-validation.js`のファイル名、種類、容量と判定条件を照合する。
