# web08 React部品カタログ

ボタン、カード、一覧、ダイアログをReact部品として分け、部品へ値や操作を渡す方法を確認するテーマです。

## このテーマでできるようになること

- 通常・強調ボタンで結果表示が変わり、無効ボタンは押せないことを確認できる
- カード部品がタイトル・説明・操作をまとめて表示することを確認できる
- 一覧部品が配列の内容を複数行で表示することを確認できる
- ダイアログを開く・閉じる操作と、開閉状態を保持するstateの関係を確認できる

## 最初に取り組むこと

次の順番で確認する。

1. 通常ボタンと強調ボタンを押し、結果表示の違いを確認する。無効ボタンは操作できないことも確認する。
2. 「ダイアログを開く」と「閉じる」を順に押し、表示と非表示が切り替わることを確認する。
3. `App.tsx`から`Button`、`Card`、`List`、`Modal`の各ファイルを辿る。
4. 各部品が受け取る値と、画面に表示する内容や実行する操作を対応させる。

## 起動方法

StudyHubのテーマ画面で「起動」を押します。手動で確認する場合は、実装ディレクトリで`npm ci`を実行してから`npm run dev`を実行します。

## 部品の役割

| 部品 | 受け取る主な値 | 役割 |
|---|---|---|
| `Button` | `variant`、`disabled`、`onClick`、`children` | 見た目、無効状態、押したときの処理、表示内容を切り替える |
| `Card` | `title`、`description`、`children` | タイトル、説明、追加の操作をひとまとまりで表示する |
| `List` | `items`、`emptyMessage` | 配列を一覧表示し、空の場合は代わりの文を表示する |
| `Modal` | `open`、`title`、`onClose`、`children` | 開閉状態に応じてダイアログを表示し、閉じる操作を親へ通知する |

## 観察ポイント

- 同じ`Button`部品へ渡す値によって、見た目と操作可否が変わるか
- `Card`部品の`children`にボタンと一覧の両方を渡せるか
- `List`部品が`map`で配列を複数行へ変換しているか
- `modalOpen`の値が`Modal`部品の表示と非表示を決めているか

## 自分の言葉で説明する

- 4つの部品に分けることで、`App.tsx`が読みやすくなる理由
- 親部品から子部品へ値を渡す流れ
- ダイアログを閉じる操作が子部品から親部品へ伝わる流れ

## うまく動かないとき

- ボタンの結果が変わらない場合は、`onClick`と`setMessage`を確認します。
- ダイアログが開閉しない場合は、`modalOpen`、`setModalOpen`、`open`の受け渡しを確認します。
- 一覧が表示されない場合は、`listItems`と`List`部品の`items`を確認します。
