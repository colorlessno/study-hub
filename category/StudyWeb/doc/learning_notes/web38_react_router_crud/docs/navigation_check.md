# 画面移動の確認手順

| 操作 | 確認するURL | 期待する画面 |
|---|---|---|
| 初期表示 | `#/items` | 一覧 |
| Alphaを選択 | `#/items/1` | 詳細 Alpha |
| Betaを編集 | `#/items/2/edit` | 編集 Beta |
| Alphaの削除確認 | `#/items/1/delete` | 削除確認 Alpha |
| 新規作成を選択して保存 | `#/items/new`から`#/items` | 作成した項目を含む一覧 |
| 項目を編集して保存 | `#/items/:id/edit`から`#/items` | 更新した名前を含む一覧 |
| 項目を削除 | `#/items/:id/delete`から`#/items` | 削除した項目を除く一覧 |
| 「対象なし例」を選択 | `#/items/999` | 対象なし |
| 不正なURL | `#/missing` | 対象なし |

一通り移動した後、教材内の戻る・進むボタンで「現在のURL」と画面が同じ履歴をたどることも確認する。

作成・更新・削除の結果はReactのstateへ反映される。DB連携は要件の対象外であるため、再読み込み後には初期データへ戻る。
