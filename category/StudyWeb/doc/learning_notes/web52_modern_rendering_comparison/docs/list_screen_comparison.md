# 一覧画面での比較

認証済みの利用者が注文一覧を開き、状態で絞り込み、詳細を開く画面を比較します。

| 方式 | データ取得と画面遷移 | 強み | 注意点 |
|---|---|---|---|
| MPA | 絞り込み条件をサーバーへ送り、ページ全体を受け取る | 入力確認とデータ取得をサーバーへまとめやすい | 操作ごとの画面遷移が増える |
| SPA | 最初の画面を表示した後、APIから一覧を取得する | 絞り込みや詳細表示を連続して操作しやすい | 読み込み中、認証切れ、通信失敗をブラウザ側で扱う |
| SSR | 最初の一覧をサーバーでHTMLにして返す | 最初から内容のある画面を返せる | 要求ごとの処理量と非公開データのキャッシュに注意する |
| SSG | 配信前に一覧のHTMLを作る | 公開され、更新が少ない一覧に向く | 認証済みで頻繁に変わる注文一覧には向きにくい |

認証済みで頻繁に変わる注文一覧では、SSRを使う案とSPAを使う案の両方が考えられます。どちらを選ぶ場合も、非公開データを共有キャッシュへ置かず、認証切れと通信失敗を画面上で扱います。
