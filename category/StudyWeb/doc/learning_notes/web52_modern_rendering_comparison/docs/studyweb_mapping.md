# StudyWeb対応表

| テーマ | 学んだ内容 | web52で使う判断 |
|---|---|---|
| web01～web06 | HTML、CSS、JavaScript、パス、フォーム | ページ、画像、入力送信の基本 |
| web07～web12 | React、状態、部品、画面操作 | ブラウザ側の操作と部品の境界 |
| web13～web18 | API、エラー、Prisma、関連データ | サーバー側のデータ取得と入力確認 |
| web19～web22 | API呼び出し、更新、通信確認、キャッシュ | SPAでの読み込み状態とキャッシュ |
| web23～web25 | Next.js、Server Components、Form Actions | サーバー側での画面生成と更新処理 |
| web26～web28 | Docker Compose、Nginx、環境変数 | 配信、実行環境、設定の分離 |
| web32～web36 | HTTP、Cookie、CORS、状態コード、localStorage | 認証、通信、保存の境界 |
| web38～web40 | 画面遷移、登録・更新・削除、表 | 連続した画面操作が必要か |
| web42～web43 | ページ分割API、重複防止 | 一覧取得と再送への対応 |
| web46～web47 | ファイル入力 | ブラウザとサーバーの入力確認 |
| web48～web49 | 長時間処理、再試行、制限時間 | 通信が終わらない場合と再試行 |
| web50～web51 | N+1問題、索引 | サーバー側でのデータ取得性能 |

web52は、個別テーマで確認した動きを一つの構成判断へつなげます。判断に迷った場合は、対応するテーマへ戻って実際の動作を確認します。
