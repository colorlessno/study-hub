# 一覧画面の状態

| 状態 | 意味 | 画面の表示 | ページ移動 |
|---|---|---|---|
| 読込中 | データを取得または処理している | 「読込中です。」 | 無効 |
| 通常表示 | 1件以上を表示できる | 表、件数、表示範囲、ページ番号 | 範囲内だけ有効 |
| 検索結果なし | 正常に検索した結果が0件 | 「条件に一致するデータはありません。」 | 無効 |
| 読込エラー | データの取得または処理に失敗した | エラー内容と通常表示へ戻す案内 | 無効 |

検索結果なしは正常な処理結果です。読込エラーと同じ表示や扱いにはしません。

総ページ数を計算し、現在ページを存在する範囲内へ補正します。最初のページでは「前のページ」、最後のページでは「次のページ」を無効にするため、データがあるのに範囲外の空ページが表示されることはありません。
