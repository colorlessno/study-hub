# 操作の確認手順

## 基本操作

1. 初期状態で17件中の1〜5件が表示されることを確認する。
2. 「次のページ」と「前のページ」で表示範囲を切り替える。
3. 「名前順」で昇順と降順を比較する。
4. 名前検索と対応状況の絞り込みを組み合わせる。
5. 一致しない名前を入力し、検索結果なしの表示を確認する。
6. 検索語を消し、1ページ目へ戻ることを確認する。
7. 読込中、読込エラー、通常表示を順番に切り替える。

## ページの境界

- 1ページ目では「前のページ」が無効になる。
- 17件を5件単位で表示すると、4ページ目が最後になる。
- 4ページ目では「次のページ」が無効になり、5ページ目へは進めない。
- 1件だけ一致する検索では、両方のページ移動ボタンが無効になる。
- 検索、絞り込み、並べ替えを繰り返しても範囲外ページにならない。

## 表示状態

- 読込中は、処理中であることが分かる文を表示する。
- 検索結果なしは、検索が正常に終わったうえで0件だったことを示す。
- 読込エラーは、処理に失敗したことと通常表示へ戻す方法を示す。
- 通常表示へ戻すと、検索条件に対応した一覧を再び操作できる。
