# web40 一覧の検索・並べ替え・ページ分割

17件のローカルデータを使い、名前検索、対応状況の絞り込み、名前順の変更、5件単位のページ移動を確認します。読込中、通常表示、検索結果なし、読込エラーの違いも同じ画面で確認できます。

## このテーマでできるようになること

- 一覧の検索、絞り込み、並べ替え、ページ移動を組み合わせて確認できる
- 最初と最後のページで、進めない方向のボタンが無効になることを確認できる
- 検索条件を変えると1ページ目へ戻る理由を説明できる
- 読込中、通常表示、検索結果なし、読込エラーの違いを説明できる

## 最初に取り組むこと

1. 教材を表示し、17件中の1〜5件と「4ページ中1ページ目」が表示されることを確認する。
2. 「次のページ」を3回押し、4ページ目では「次のページ」が無効になることを確認する。
3. 「前のページ」で1ページ目へ戻り、「前のページ」が無効になることを確認する。
4. 「名前順」を押し、昇順と降順で表示順が変わることを確認する。
5. 名前検索と対応状況を組み合わせ、条件を変えるたびに1ページ目へ戻ることを確認する。
6. 一致しない名前を入力し、「条件に一致するデータはありません。」と表示されることを確認する。
7. 「確認する表示状態」で読込中と読込エラーを選び、通常表示や検索結果なしとは異なる表示になることを確認する。

## 操作と実装の対応

| 画面の操作 | 状態の変更 | 一覧への反映 |
|---|---|---|
| 名前を入力する | 検索語を変更し、ページを先頭へ戻す | 名前の部分一致で絞り込む |
| 対応状況を選ぶ | 対応状況を変更し、ページを先頭へ戻す | 対応中または完了だけに絞り込む |
| 名前順を押す | 昇順と降順を切り替え、ページを先頭へ戻す | 絞り込み後の一覧を並べ替える |
| 前後のページを押す | 現在ページを変更する | 1ページ5件を表示する |
| 表示状態を選ぶ | 通常、読込中、読込エラーを切り替える | 状態に対応した内容を表示する |

一覧は、検索と絞り込み、並べ替え、ページ分割の順に計算します。現在ページが範囲外にならないように補正し、最初と最後のページでは該当する移動ボタンを無効にします。

## 確認すること

- 検索と絞り込みを先に行うため、件数と総ページ数が条件に合わせて変わる
- 並べ替えは、絞り込まれた全件に対して行ってから5件を取り出す
- 検索結果なしは正常な検索結果であり、読込エラーとは異なる
- 読込中と読込エラーではページ移動を行えない
- 表の見出し、入力欄のラベル、ボタンの無効状態が画面上で確認できる

## 自分の言葉で説明する

- 検索、並べ替え、ページ分割の順番を変えると結果がどう変わるか
- 検索条件変更時にページを先頭へ戻す理由
- 検索結果なしと読込エラーの違い
- クライアント側のページ分割と、サーバー側のページ分割を使い分ける基準

## うまく動かないとき

- 教材を再表示し、初期状態へ戻してから操作をやり直す。
- 表示内容が変わらない場合は、ブラウザ開発者ツールのコンソールでJavaScriptエラーを確認する。
- READMEの操作順と実画面のラベルが一致していることを確認する。
