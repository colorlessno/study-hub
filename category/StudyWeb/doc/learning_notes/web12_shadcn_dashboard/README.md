# web12 shadcn/ui風の管理画面

React、Tailwind CSS、lucide-reactで、管理画面のサイドバー、ヘッダー、指標カード、テーブルを組み立てるテーマです。shadcn/ui本体は使用せず、構成と見た目を学びます。

## このテーマでできるようになること

- サイドメニュー・ヘッダー・集計カード・一覧表の4つの画面部品を確認できる
- サイドメニューを選び、選択状態とヘッダーの見出しが切り替わることを確認できる
- 画面幅を変え、メニューや集計カードの配置が切り替わることを確認できる
- 一覧表の名称・状態・更新日が日本語で表示されることを確認できる

## 最初に取り組むこと

次の順番で確認する。

1. 画面を起動し、サイドメニュー、ヘッダー、集計カード、一覧表の役割を確認する。
2. サイドメニューを順に選び、選択中の背景色、ヘッダーの見出し、選択結果の文が変わることを確認する。
3. 画面幅を変え、集計カードの列数とサイドメニューの配置が変わる位置を確認する。
4. 対応するTailwind CSSの`md`、`lg`から始まるクラスを探し、適用条件を画面幅と照合する。
5. 一覧表を狭い幅で確認し、内容を縮小せず表の外枠内で横スクロールできる理由を確認する。
6. `App.tsx`から各部品を辿り、情報を集計カードと一覧表へ分ける構成を確認する。

## 起動方法

実装ディレクトリで実行します。

```bash
npm install
npm run dev
```

型チェックと本番ビルドは`npm run build`で確認します。

## 観察ポイント

- 選択したメニューだけ背景色が変わり、ヘッダーの見出しにも反映されるか
- `lg`以上でサイドメニューが240pxの左列になるか
- `lg`未満でサイドメニューと本文が縦に並ぶか
- `md`以上で指標カードが3列になるか
- 560px未満でテーブル外枠内を横スクロールできるか
- メニュー、集計値、一覧表で、各データを識別できる値がReactの`key`に使われているか
- lucide-reactのアイコンがメニュー識別の補助になっているか

## 自分の言葉で説明する

- `App`と4つの子部品の役割を説明してください。
- サイドメニューを常に横へ置かず、`lg`以上だけ2列にする理由は何ですか。
- 「shadcn/ui風」であってshadcn/ui本体ではない、とはどういう意味ですか。

## うまく動かないとき

- Tailwindが反映されない場合は、`index.css`、Tailwind設定、開発サーバーのログを確認します。
- アイコンが出ない場合は、lucide-reactのimportと依存関係を確認します。
- 表が画面全体を押し広げる場合は、外枠の`overflow-x-auto`を確認します。
