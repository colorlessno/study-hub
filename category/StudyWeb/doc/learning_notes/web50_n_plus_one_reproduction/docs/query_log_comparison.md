# 問い合わせ回数の比較

| 方式 | 親3件 | 親10件 | 返されるデータ |
|---|---:|---:|---|
| N+1方式 | 4回 | 11回 | 利用者とタスク |
| 改善後 | 親件数に比例しない | 親件数に比例しない | 同じ利用者とタスク |

## 実行結果で見る場所

- `parentCount`: 指定した親データの件数
- `queries`: Prismaが発行したSQLの合計回数
- `queryLog`: SQL、parameter、各SQLの実行時間
- `durationMs`: 取得処理全体の実行時間
- `result`: 組み立てられた利用者とタスク

本テーマではSQLiteへ実際に発行されたSQLを記録します。小さい開発データだけでは時間差が見えにくいため、主にSQL回数と増え方を確認します。
