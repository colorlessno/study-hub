# web51 DB索引あり・なしの検索比較

PostgreSQLへ商品データを作り、同じ検索SQLの実行計画を索引の作成前後で比較するテーマです。

## このテーマでできるようになること

- 学習用データベースへテーブルと10,000件の商品を作成できる
- 索引を作る前後で、同じ検索SQLの実行計画を取得できる
- 全件走査と索引走査の違いを実行結果から確認できる
- 索引が検索を助ける一方、更新処理と保存容量を使うことを説明できる

## 最初に取り組むこと

1. Docker Desktopが起動していることを確認し、「起動」を押す。
2. 「比較用データを準備」を実行し、テーブルと10,000件のデータを作る。
3. 「索引作成前を計測」を実行し、走査方法、対象行数、実行時間、読み込んだページを確認する。
4. 「索引を作成」を実行する。
5. 「索引作成後を計測」を実行し、同じ項目を索引作成前の結果と比較する。
6. 「実行計画で見る項目」と「テーブル作成SQL」を開き、実行結果とSQLを照合する。
7. 確認後に「停止」を押し、このテーマ専用のコンテナとデータを削除する。

## 比較する項目

| 項目 | 確認する内容 |
|---|---|
| 走査方法 | `Seq Scan`または`Index Scan` |
| 対象行数 | 見積り件数と実際の件数 |
| 実行時間 | 同じ条件で複数回比較する |
| 読込量 | `Buffers`の`hit`と`read` |

索引があっても、データ量、条件に合う件数、キャッシュの状態によって全件走査が選ばれる場合があります。1回の時間だけで判断せず、実行計画全体を確認します。

## この教材で扱わないこと

- 複合索引、部分索引、全文検索
- 本番データベースの索引変更
- 更新処理への負荷や保存容量の実測

## 手動で確認する場合

StudyHubを使わずに確認する場合も、削除可能な学習用PostgreSQLだけを使用します。SQLは次のファイルにあります。

```text
category\StudyWeb\src\backend\src\studyweb\systems\web51_index_search_comparison\db\schema.sql
category\StudyWeb\src\backend\src\studyweb\systems\web51_index_search_comparison\db\seed.sql
```

案内用JavaScriptの構文は次のコマンドで確認できます。

```bat
cd /d C:\work\work20260617\category\StudyWeb\src\backend\src\studyweb\systems\web51_index_search_comparison
rtk npm.cmd run build
```

## うまく動かないとき

- 起動できない場合はDocker Desktopの状態を確認する。
- 計測前に「比較用データを準備」を実行する。
- 索引作成後の結果が変わらない場合は、`Index Scan`の有無だけでなく、対象行数と実行時間も比較する。
- 初期状態からやり直す場合は、「停止」の後にもう一度「起動」する。
