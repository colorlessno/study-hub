# 索引作成前後の比較手順

## 画面で実行する順番

1. 「起動」で学習用PostgreSQLを起動する。
2. 「比較用データを準備」でテーブルと10,000件の商品を作る。
3. 「索引作成前を計測」で実行計画を取得する。
4. 「索引を作成」で商品名の索引を作る。
5. 「索引作成後を計測」で同じ検索SQLの実行計画を取得する。
6. 確認後に「停止」でコンテナとデータを削除する。

## 同じ条件で比較するSQL

```sql
EXPLAIN (ANALYZE, BUFFERS)
SELECT * FROM products WHERE name = 'product-9999';
```

比較時は、走査方法、見積り件数、実際の件数、実行時間、`Buffers`を記録します。索引を作る前後で検索条件やデータを変えないことが重要です。

この教材の初期化SQLは`products`テーブルを削除して作り直します。共有環境や本番環境では実行しません。
