# 実行計画で見る項目

| 表示項目 | 確認する内容 |
|---|---|
| 走査方法 | `Seq Scan`、`Index Scan`など、データの探し方 |
| `cost` | PostgreSQLが見積もった相対的な処理量 |
| `rows` | 見積り件数と実際に処理した件数 |
| `loops` | 各処理を繰り返した回数 |
| `Planning Time` | 実行方法を決めるまでの時間 |
| `Execution Time` | SQLを実行した時間 |
| `Buffers` | メモリ上またはディスクから読んだページ |

## 比較するときの注意

- 1回の実行時間だけで結論を出さない
- キャッシュの状態で結果が変わる
- 小さいテーブルでは全件走査が適切な場合がある
- 索引があっても、検索条件が合わなければ使われない
- 索引は登録・更新・削除と保存容量にも負荷を加える

実行計画は索引を強制的に使わせるためではなく、PostgreSQLが選んだ方法と実際の処理を理解するために確認します。
