# web07 Reactカウンター

Reactの`useState`で数値を保持し、ボタン操作による状態変更と画面の再表示を確認するテーマです。

## このテーマでできるようになること

- 加算・減算・リセットの各ボタンが正しく動くことを確認できる
- useStateが現在の数値を保持していることを確認できる
- ボタンのonClickで数値を変更すると、画面が再表示されることを確認できる

## 最初に取り組むこと

次の順番で確認する。

1. 画面を起動し、加算を2回、減算を1回押して表示が`1`になることを確認する。
2. リセットを押し、表示が`0`へ戻ることを確認する。
3. `App.tsx`で`count`と`setCount`の宣言を探し、各ボタンの処理と対応させる。
4. `setCount`の実行後に関数部品が再実行され、`count`の表示が更新される流れを確認する。

## 起動方法

StudyHubのテーマ画面で「起動」を押します。手動で確認する場合は、実装ディレクトリで`npm ci`を実行してから`npm run dev`を実行します。

## 観察ポイント

- 初期表示は`0`か
- 加算と減算は、直前の値を受け取る書き方で更新しているか
- リセットは値を`0`へ置き換えているか
- HTMLを直接書き換えず、stateの変更によって表示が更新されているか

## 自分の言葉で説明する

- `useState(0)`が返す2つの値の役割
- ボタンを押してから数値が変わるまでの流れ
- 通常の変数ではなくstateで数値を保持する理由

## うまく動かないとき

- 起動できない場合は、依存パッケージとViteの実行ログを確認します。
- ボタンが反応しない場合は、各ボタンの`onClick`と`setCount`を確認します。
- 値が予想と違う場合は、加算・減算・リセットの式を1つずつ確認します。
