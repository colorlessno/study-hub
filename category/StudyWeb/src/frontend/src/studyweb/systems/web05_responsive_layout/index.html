CSS Grid とメディアクエリで、画面幅に応じて列数が変わるカード一覧を作ります。

HTML

構造を作る

見出し、段落、リストなどでページの骨組みを作ります。

CSS

見た目を整える

余白、色、枠線、配置を使って読みやすい画面にします。

CSS Grid（格子状配置）

一覧を並べる

カードを複数列に並べ、画面幅に合わせて調整します。

Flexbox（並び方の調整）

部品を揃える

ボタンやラベルの配置を細かく制御します。

画面幅への対応

小さい画面に対応

スマートフォン幅では1列表示に切り替えます。

ブラウザ開発者ツール

幅を確認する

デバイスモードで横スクロールが出ないことを確認します。

PC幅、タブレット幅、スマートフォン幅でカード列数を確認してください。
