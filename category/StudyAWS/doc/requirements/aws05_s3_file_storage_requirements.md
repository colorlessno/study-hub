# aws05 S3ファイル保存 要件定義

## 1. 目的

オブジェクトストレージの基本を、LocalStackまたはローカル疑似ストレージで確認し、業務ファイル保存へつなげる。

## 2. 学習対象

- bucket、object key、metadata
- public / privateの違い
- presigned URLの概念
- versioning、lifecycle、削除
- ファイルアップロード処理との接続

## 3. 要件

- まずローカル疑似ストレージで、アップロード、一覧、取得、削除を確認する。
- LocalStackが利用できる場合はS3互換APIで同じ流れを確認する。
- 実S3は発展課題として、公開設定、削除、課金注意を明記する。
- 実ファイルや個人情報を含むファイルは使わず、ダミーファイルで確認する。

## 4. 成果物

- S3概念メモ
- ローカル疑似ストレージ要件
- S3操作チェックリスト
- 公開設定ミス防止メモ

## 5. 完了条件

- DB保存とオブジェクトストレージ保存の違いを説明できる。
- private bucketを前提にした保存設計を説明できる。
- presigned URLの使いどころを説明できる。
