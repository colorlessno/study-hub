# aws03 EC2 + SSH 要件定義

## 1. 目的

仮想サーバーの起動、SSH接続、プロセス起動、ログ確認の基本を、ローカル疑似環境と実AWS発展課題に分けて学ぶ。

## 2. 学習対象

- EC2、AMI、instance type、key pair
- SSH公開鍵 / 秘密鍵
- Linux上のプロセス起動、port確認、ログ確認
- セキュリティグループとの関係
- ローカルLinuxコンテナでの疑似操作

## 3. 要件

- ローカルではDockerコンテナを仮想サーバー相当として扱い、SSHではなくshell接続、プロセス起動、port確認を学ぶ。
- 実AWS EC2は発展課題として、起動、SSH、停止、削除、課金注意を明記する。
- 秘密鍵や認証情報はリポジトリに置かない。
- 接続できない場合の確認観点を整理する。

## 4. 成果物

- EC2概念メモ
- ローカル疑似サーバー手順
- SSH接続チェックリスト
- 実AWS発展課題の注意事項

## 5. 完了条件

- EC2とローカルコンテナの違いを説明できる。
- SSH鍵とSecurity Groupの関係を説明できる。
- サーバー上でアプリが起動しているか確認できる。
