# aws10 バックアップ / リストア 要件定義

## 1. 目的

DBやファイルを壊した時に戻せるよう、バックアップ、リストア、保持期間、復旧確認を学ぶ。

## 2. 学習対象

- DB dump / restore
- object storage backup
- retention period
- RPO / RTOの入口
- dry runと復旧テスト

## 3. 要件

- ローカルPostgreSQLまたはファイルを対象に、バックアップとリストアの流れを疑似確認する。
- 実データは使わず、ダミーデータのみを使う。
- 削除や上書きはドライランを優先し、実行対象パスを明示する。
- 実AWSのRDS snapshotやS3 versioningは発展課題として整理する。

## 4. 成果物

- バックアップ方針メモ
- ローカル復旧手順
- 復旧確認チェックリスト
- 実AWS発展課題の注意事項

## 5. 完了条件

- バックアップとリストアの違いを説明できる。
- 復旧テストの重要性を説明できる。
- RPO / RTOの入口を説明できる。
