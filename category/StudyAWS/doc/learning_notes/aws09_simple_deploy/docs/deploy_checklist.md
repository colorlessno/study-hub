# デプロイ前後チェック

## 起動前

- Docker imageをbuildできるか。
- `.env.example`に必要な環境変数の名前だけがあり、実秘密情報がないか。
- コンテナが非rootユーザーでAPIを起動するか。

## 起動後

- `/health`が状態コード200を返すか。
- 利用者向けURLとhealth check用URLを区別できるか。
- 起動ログとリクエストログを確認できるか。
- 障害時の状態コードと復旧後の状態を確認できるか。
- 停止時に教材用コンテナが削除されるか。

実クラウドへ公開する場合は、公開URL、削除手順、課金、認証情報の管理方法も別途確認する。
