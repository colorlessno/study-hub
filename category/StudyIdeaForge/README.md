# IdeaForge 発想支援アプリ

AIと人間が協働してアイデアを育てる発想支援アプリケーション「IdeaForge」を収録しています。発想法をノードとしてグラフ化し、生成結果の採用、修正、再生成を人間が判断しながら進めます。

## このテーマでできるようになること

- LLMを使わずにアプリを起動し、画面操作とSQLiteへの保存を確認できる
- 画面、API、SQLiteがどのようにデータを受け渡すか説明できる
- 発想手順を編集し、保存した内容が再読み込み後も残ることを確認できる
- 発想手順の初期データと、手順を動かす処理の対応をソースから追える
- ローカルLLMが必要な処理と、LLMなしで確認できる処理を区別できる
- SQLite保存処理のテストが確認している範囲を説明できる

## 最初に取り組むこと

1. StudyHubの「起動」を押し、IdeaForgeの画面が表示されることを確認する。
2. 発想手順を複製し、名前や配置を変更して保存する。
3. 画面を再読み込みし、変更した内容がSQLiteから復元されることを確認する。
4. StudyHubの資料切替で、画面からAPI、SQLiteへ処理が流れるソースを順番に読む。
5. SQLite保存処理のテストを開き、通常のデータベースとは別の一時ファイルを使う理由を確認する。

この確認にはLM Studioは不要です。発想内容の生成、採用、修正、再生成を確認するときだけローカルLLMを使用します。

主な技術はFastAPI、SQLite、React、Viteです。文章生成にはOpenAI互換APIを使用し、LM StudioなどのローカルLLMも接続できます。

このプロジェクトは番号付き教材とは異なり、1つのアプリケーションを題材に、AIワークフロー、状態保存、画面操作、LLM連携を横断して確認する位置付けです。

リポジトリの先頭フォルダから次を実行すると、LLM、APIキー、実際のアプリ用データベースを使わずにSQLiteの初期化と状態保存を確認できます。

```cmd
python -m unittest discover -s category\StudyIdeaForge\ideaforge\backend\tests -v
```
