# arch02 レビュー対象の期待仕様

## 対象

arch02内で独立して起動するタスク登録システムを対象とする。

## 期待する動作

- ブラウザ画面からタスクを登録できる。
- `POST /api/tasks` はタスクをSQLiteへ保存し、HTTP 201を返す。
- `GET /api/tasks` はSQLiteに保存されたタスクを返す。
- `/health` はHTTPサーバーの稼働、`/ready` はAPIとSQLiteの利用可能状態を返す。
- 各API要求はTrace ID、HTTPメソッド、パス、状態コードとともにログへ残る。
- レビュー結果は発見事項、影響、修正案、対応状態（未対応、対応済み、リスク受容）、残リスクを持ち、SQLiteへ保存される。

## 教材として組み込んだ差異

レビューで発見する対象として、`POST /api/tasks` の実装はHTTP 202を返す。期待仕様の201との差を、API応答と実行ログから確認する。
