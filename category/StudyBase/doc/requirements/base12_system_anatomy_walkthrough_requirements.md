# base12 要件定義

## 目的

StudyBaseで基礎的な開発作業を学んだ利用者が、システム構成を読み解く正規テーマarch01へ迷わず移動できるようにします。base12には同じ演習を複製せず、学習内容と進捗の管理先をarch01へ統一します。

## 利用する場面

- StudyBaseの最後からシステム構成の学習へ進む
- base12とarch01の違いを確認する
- システム構成の記入例やひな形を探す

## 画面で行うこと

- base12が案内入口であることを確認できる
- 正規テーマがarch01であることを確認できる
- 画面内のリンクからarch01へ移動できる
- arch01専用システムの概要と、arch01で使用する整理ひな形を確認できる
- 学習項目と進捗をarch01へ記録することを確認できる

## 表示する内容

| 表示 | 内容 |
|---|---|
| 入口の説明 | StudyBaseからStudyArchitectureへ進む位置 |
| 正規テーマ | arch01「システム構造の読み解き」 |
| 移動リンク | StudyHubのarch01テーマ画面 |
| 学習内容の概要 | arch01専用の注文登録システム、構成要素、処理の流れ、失敗時の動き、構成判断 |
| 進捗の扱い | 学習本体の進捗はarch01へ記録する |

## 対象外

- base12内でarch01と同じ演習を実装すること
- base12用にシステム構成のひな形や記入例を複製すること
- 実在企業の秘密情報や顧客情報を扱うこと

## 安全性

- リンク先はStudyHub内のarch01に限定する
- base12から外部サービスを起動しない
- base12で入力やファイル保存を行わない
- テキストファイルはUTF-8（BOMなし）で管理する

## 受入条件

- base12の画面だけで、このテーマの役割と正規テーマが分かる
- 「arch01を開く」リンクから正規テーマへ移動できる
- arch01専用システムと整理ひな形の概要が分かる
- base12とarch01に同じ学習教材を重複して置かない
