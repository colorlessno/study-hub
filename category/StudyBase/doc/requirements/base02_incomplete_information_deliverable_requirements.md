# base02 情報不足時の暫定成果物 要件定義

## 目的

情報が不足した依頼でも、確認できた事実と判断できない事項を分け、利用条件を明記した暫定成果物を作成できるようにする。

## 利用者が画面で行うこと

- 依頼内容、入手済み情報、不足情報、情報源、確認日を記録する。
- 書ける範囲、書けない範囲、暫定内容を記録する。
- 仮定に根拠、影響、確認先、状態を付ける。
- 未確定事項に確認内容、確認先、期限、未解決時の影響を付ける。
- 成果物の限界、利用してよい範囲、利用してはいけない範囲、レビュー観点を記録する。
- 入力内容を保存し、4種類の文書をプレビューまたはダウンロードする。

## 入力

| 入力 | 内容 |
|---|---|
| 依頼と情報源 | 依頼内容、入手済み情報、不足情報、情報源、確認日 |
| 対象範囲 | 目的、対象範囲、書ける範囲、書けない範囲、暫定内容 |
| 仮定 | 仮定、根拠、影響、確認先、状態 |
| 未確定事項 | 不明点、確認内容、確認先、期限、未解決時の影響 |
| 利用条件 | 利用可能範囲、利用禁止範囲、限界、レビュー観点、確認待ち |

## 出力

- 暫定成果物
- 前提・仮定一覧
- 未確定事項一覧
- 成果物限界メモ

出力はMarkdownとし、選択中の文書をファイルとして保存できるようにする。

## 保存と復元

入力内容はブラウザのローカルストレージへ保存する。画面を再表示したときに復元し、利用者の操作で消去できるようにする。

## 安全性

- 入力値をHTMLとして実行しない。
- 外部サービスへ入力内容を送信しない。
- 秘密情報、個人情報、実顧客情報を入力しない注意を表示する。
- 不明点を事実として補完しない。

## 対象外

- 関係者への問い合わせ送信
- 正式な仕様書の承認
- 複数の仮定や未確定事項を行追加する機能

## 受入確認

- 固定シナリオを読み込める。
- 必須項目が不足している場合は保存とダウンロードを行わない。
- 4種類の文書を切り替えて確認できる。
- 保存後の再表示で入力内容を復元できる。
- 保存内容を消去できる。
