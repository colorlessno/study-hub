# base05 RACI・責任分担

作業と判断を、実施者、最終承認者、相談先、共有先へ分け、責任の空白や重複を見つけます。

## このテーマでできるようになること

- 対象案件と関係者を役割名で整理できる
- 作業ごとにResponsible、Accountable、Consulted、Informedを記録できる
- 作業を実施する役割と最終判断を行う役割を区別できる
- 判断待ち事項に決定者、期限、未決時の影響を記録できる
- 自分の役割では決められない事項を依頼先と期限付きで記録できる
- RACI表、判断待ち事項一覧、エスカレーションメモをMarkdownとして保存できる

## 最初に取り組むこと

1. 「固定シナリオを読み込む」を押し、対象案件と関係者の役割を確認する。
2. 作業ごとにR、A、C、Iがどのように分けられているか確認する。
3. RとAには1つの役割だけが記録されていることを確認する。
4. 判断待ち事項の決定者、期限、未決時の影響を確認する。
5. エスカレーションの理由、影響、依頼先、期限を確認する。
6. 整合性を確認し、3種類の文書を切り替えて保存する。

## 画面で作成する文書

- RACI表
- 判断待ち事項一覧
- エスカレーションメモ

入力内容はブラウザ内に保存されます。個人名ではなく役割名を使い、秘密情報や社外秘の組織情報は入力しないでください。
