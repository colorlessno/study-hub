# base11 ポートフォリオのデモ・説明

学習成果物を大きく見せるのではなく、作ったもの、確認した事実、未確認の範囲を分けて説明します。画面に自分の成果物を入力し、60秒、3分、5分の説明案と録画構成を作成します。

## このテーマでできるようになること

- 説明する成果物と聞き手を決められる
- 説明する内容と証拠を対応付けられる
- 説明時間に合わせて内容の詳しさを変えられる
- 実装済みの事実、未確認の範囲、今後の予定を分けて説明できる

## 到達目標

- 見せる対象を1つの利用者の操作へ絞る
- 主張を画面、API応答、実行ログ、テスト結果、ソースで裏付ける
- 現在の制限と次の改善を誇張せずに示す

## 最初に取り組むこと

1. StudyHubでbase11を開く
2. 「記入例を読み込む」を押し、入力項目を確認する
3. 60秒、3分、5分の説明案を順番に作成し、追加される内容を比べる
4. 録画構成を作成し、画面で見せる順番を確認する
5. 入力内容を自分の成果物に置き換える

## 画面へ入力する内容

| 入力 | 書く内容 |
|---|---|
| 成果物の名前 | 説明するテーマやアプリの名前 |
| 想定する聞き手 | 学習者、採用担当者、開発者など |
| 解決する問題 | 誰の何が不便なのか |
| 利用者が行う主な操作 | 実際に見せる一連の操作 |
| 主な構成 | 画面、API、データ保存などの関係 |
| 確認できた事実 | テストや実行で確認した結果 |
| 見せる証拠 | 主張を裏付けるものを3件まで |
| 現在の制限 | 未実装または未確認の範囲 |
| 次に改善すること | 制限に対する具体的な次の作業 |

## 説明案の違い

| 説明案 | 含める内容 |
|---|---|
| 60秒 | 作ったもの、主な操作、構成、確認結果、制限 |
| 3分 | 60秒版に、問題、証拠、説明の順番を追加 |
| 5分 | 3分版に、設計上の説明と失敗時に示す事実を追加 |
| 録画構成 | 画面で何をどの順番に見せるか |

## 操作できないとき

未入力の項目がある場合は、説明案の代わりに不足している項目名が表示されます。個人情報、秘密情報、顧客情報は入力しないでください。
