# 対象選定

## 選定基準

| 基準 | 良い対象 |
| --- | --- |
| 見える結果 | 画面、コマンド、API応答、報告書、実行ログ |
| 説明できる構成 | 構成要素とデータの流れが明確 |
| 証拠がある | テスト結果、画面、文書、コミット、実行ログ |
| 範囲が小さい | 3分で説明できる |
| 正直な制限がある | 次の改善が明確 |

## 候補表

| 候補 | 結果 | 証拠 | 注意点 |
| --- | --- | --- | --- |
| StudyDB db02 | SQLによる登録・参照・更新・削除と表の結合 | SQLファイル、コマンド結果 | 視覚的には伝わりにくい |
| StudyWebの画面テーマ | ブラウザ上の操作と変化 | 画面、画面遷移のソース | アプリの起動が必要 |
| StudyAI system47 | 集計と説明 | SQL、指示文、出力例 | AIの出力を実績として過大に扱わない |

## 判断

説明文を書く前に、主に見せる成果物と、代わりに見せられる成果物を1つずつ選ぶ。
