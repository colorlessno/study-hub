# 証拠選定

## 証拠の種類

| 証拠 | 良い使い方 |
| --- | --- |
| 画面 | 利用者に見える結果 |
| コマンドの結果 | コマンド操作やDocker環境の確認 |
| テスト結果 | 変更後も期待する動作を保てている事実 |
| 構成図 | システムの構成やデータの流れの説明 |
| ソース | 重要な処理の実装内容 |
| README | 実行方法 |

## 証拠ルール

主張を証明する最小の証拠を使う。

悪い例:

```text
これは本番環境で利用できます。
```

良い例:

```text
ローカル環境では正常な入力による基本動作を確認しています。複数利用者が同時に操作する場合の動作は未確認です。
```
