# 動画構成

## shot list

| segment | screen |
| --- | --- |
| 最初 | アプリ、コマンド、または結果画面 |
| problem | 短いtitleまたはREADME section |
| 操作 | 実際の操作手順 |
| 構成 | 構成図またはフォルダ構成 |
| 確認結果 | テスト、コマンド、または実行ログ |
| 制限 | 次の改善を添えた短い説明 |

## recording checklist

- 無関係なwindowを閉じる。
- 読みやすいfont sizeにする。
- terminal outputを絞る。
- 大きなファイルを長くスクロールしない。
- 実装詳細を説明する前に結果を見せる。

## 最終確認

録画後に、視聴者が以下を答えられるか確認する。

1. 何の問題を解くものか。
2. 何を作ったか。
3. どう検証したか。
4. 何がまだ制限か。
