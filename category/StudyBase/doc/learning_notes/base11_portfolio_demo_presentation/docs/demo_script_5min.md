# 5分の説明ひな形

## 構成

1. 背景と問題
2. 主な操作の実演
3. 重要な設計判断。
4. 失敗例または境界条件
5. 検証証拠。
6. 制限と次の改善

## 時間配分

| 時間 | 内容 |
| ---: | --- |
| 0:00-0:40 | 背景と問題 |
| 0:40-2:00 | 主な操作の実演 |
| 2:00-3:00 | システム構成と設計判断 |
| 3:00-3:40 | 失敗例または境界条件 |
| 3:40-4:30 | 検証証拠 |
| 4:30-5:00 | 制限と次の改善 |

## 追加する価値

5分版では、説明する機能を増やすのではなく、証拠と設計上の取捨選択を追加します。
