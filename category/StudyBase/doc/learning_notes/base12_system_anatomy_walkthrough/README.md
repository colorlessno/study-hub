# base12 システム構成を読み解く入口

base12は、IT基礎からシステム構成の学習へ進むための案内入口です。システムの構成要素、処理の流れ、失敗時の動き、構成理由を読み解く教材は、StudyArchitectureのarch01で管理します。

同じ教材をbase12とarch01へ重複して置くと、内容や進捗がずれるため、学習本体はarch01だけを使用します。

## 最初に取り組むこと

1. [arch01「システム構造の読み解き」を開く](/themes/arch01?catalog=actual)
2. arch01の「最初に取り組むこと」で、対象がarch01専用の注文登録システムになっていることを確認する
3. arch01の教材欄で、対象システム概要、構成整理、処理の流れ、失敗時の動きを確認する
4. 以降の学習項目と進捗はarch01へ記録する

## base12で確認すること

- StudyBaseの学習から、システム構成を扱うStudyArchitectureへ進む位置を確認する
- 正規テーマがarch01であり、base12に同じ演習を複製しない理由を確認する
- arch01の画面へ直接移動できることを確認する

## arch01で扱う内容

arch01では、専用の注文登録システムを対象に、利用者から見える動作、画面、API、SQLite、ログの構成要素、処理とデータの流れ、失敗時の動き、構成判断の根拠を整理します。確認した事実と推測を分け、対象システム概要と整理ひな形を使って説明します。他のStudyテーマをarch01の起動対象や保存先として使用しません。

## 移動できないとき

上のリンクで移動できない場合は、分野一覧から「システム構成・設計」を開き、arch01を選びます。StudyHubは実テーマ表示へ切り替えて使用してください。
