# base02 情報不足時の暫定成果物

情報が不足した依頼に対し、確認できた内容だけで暫定成果物を作ります。推測した内容は仮定として分け、未確定事項と利用上の限界を明記します。

## このテーマでできるようになること

- 入手済み情報と不足情報を分けて記録できる
- 書ける範囲と書けない範囲を根拠に沿って分けられる
- 仮定に根拠、影響、確認先、状態を付けられる
- 未確定事項に確認内容、確認先、期限、未解決時の影響を付けられる
- 暫定成果物の利用範囲と利用してはいけない範囲を明記できる
- 4種類の文書を画面で確認し、Markdownとして保存できる

## 最初に取り組むこと

1. 「固定シナリオを読み込む」を押し、入手済み情報と不足情報を確認する。
2. 「書ける範囲」と「書けない範囲」が情報源に沿って分けられているか確認する。
3. 仮定の根拠と影響、未確定事項の確認先と期限を確認する。
4. 利用してよい範囲、利用してはいけない範囲、成果物の限界を確認する。
5. 入力内容を保存し、4種類のプレビューを切り替える。
6. 表示中の文書をダウンロードし、入力内容が反映されていることを確認する。

## 画面で作成する文書

- 暫定成果物
- 前提・仮定一覧
- 未確定事項一覧
- 成果物限界メモ

入力内容はブラウザ内に保存されます。実在する顧客名、個人情報、秘密情報は入力しないでください。
