# base10 curlによるAPI確認

画面を介さずAPIへ直接リクエストを送り、HTTPメソッド、URL、ヘッダー、本文、状態コード、応答本文の関係を確認します。

## このテーマでできるようになること

- 正常な取得と登録で200・201を確認できる
- 不正入力、未認証、権限不足、存在しないURL、許可されていないHTTPメソッドを区別できる
- 大きすぎる本文と対応していないContent-Typeを区別できる
- API内部の失敗と接続先サービスの失敗を500・502で区別できる
- 状態コードだけでなく、送信内容、応答ヘッダー、応答本文を合わせて確認できる

## 最初に取り組むこと

1. StudyHubの「起動」を押し、`127.0.0.1`だけでAPIが待ち受け、状態が「利用可能」になることを確認する。
2. 「実行する処理」で各確認項目を選び、「実行する」を押す。
3. 実行結果の`statusCode`、`headers`、`output`を確認する。
4. 「API確認ログ」を開き、送信した内容と応答を対応させる。
5. 確認後に「停止」を押す。

| 操作 | 確認する状態コード | 意味 |
|---|---:|---|
| 起動確認 | 200 | APIが要求を正常に処理した |
| 項目登録 | 201 | 新しい項目を作成した |
| 名前なしで登録 | 400 | 入力内容が不正だった |
| 認証情報なし | 401 | 認証が必要だった |
| 権限不足 | 403 | 認証後の権限が不足していた |
| 存在しないURL | 404 | 対象のURLが存在しなかった |
| 許可されていないHTTPメソッド | 405 | URLは存在するがHTTPメソッドが違った |
| 大きすぎる本文 | 413 | リクエスト本文が上限を超えた |
| 対応していないContent-Type | 415 | APIが受け付けない形式で送信した |
| API内部のエラー | 500 | API内部で処理に失敗した |
| 接続先サービスのエラー | 502 | APIの接続先から正常な応答を得られなかった |

StudyHubを使わずにまとめて確認する場合は、リポジトリのルートで次を実行します。

```cmd
rtk node category\StudyBase\scripts\validate-studybase.mjs base10
```

サンプルAPIを単独で起動する場合は、次を実行し、`http://127.0.0.1:3010/`へ接続します。終了するときは`Ctrl+C`を押します。

```cmd
rtk npm.cmd --prefix category\StudyBase\src\samples\base10_curl_api_check\sample_api start
```
