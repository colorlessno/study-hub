# base03 見積り根拠

数字を先に決めず、対象範囲、対象外、前提、作業分解、リスク、再見積り条件から見積りを説明します。

## このテーマでできるようになること

- 見積りに含む範囲、対象外、前提を分けて記録できる
- 作業を工程、内容、成果物、工数、根拠へ分解できる
- 作業別の工数から合計工数を確認できる
- 変動要因を発生条件、影響、対策、見積りへの影響へ分けられる
- 数字が変わる条件と再見積りの時点を示せる
- 3種類の文書を画面で確認し、Markdownとして保存できる

## 最初に取り組むこと

1. 「固定シナリオを読み込む」を押し、依頼、見積り対象、対象外、前提を確認する。
2. 作業ごとに工程、内容、成果物、工数、根拠が対応していることを確認する。
3. リスクごとに発生条件、影響、対策、見積りへの影響が対応していることを確認する。
4. 合計工数と再見積り条件を確認する。
5. 入力内容を保存し、3種類のプレビューを切り替える。
6. 表示中の文書をダウンロードし、入力内容が反映されていることを確認する。

## 画面で作成する文書

- 見積り根拠表
- 作業分解表
- リスク一覧

入力内容はブラウザ内に保存されます。実在する顧客名、個人情報、秘密情報は入力しないでください。
