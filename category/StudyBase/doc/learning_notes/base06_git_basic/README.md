# base06 Git基本操作

Gitの変更状態を、実際のコマンド結果から確認するテーマです。練習原本を一時フォルダへコピーしてからGitリポジトリを作るため、教材原本とStudyHub本体は変更しません。

## このテーマでできるようになること

- 作業フォルダ、ステージ、コミットの違いを説明できる
- `git status`、`git diff`、`git diff --staged`を使い分けられる
- 意図した変更だけをステージし、コミット後の履歴を確認できる
- `.gitignore`により、履歴へ入れないファイルを確認できる

## 最初に取り組むこと

1. StudyHubの「操作」から「すべての状態を順番に確認」を選ぶ。
2. 「すべての状態を順番に確認」を押す。
3. 変更前、未ステージ、ステージ済み、コミット済み、除外対象の順に出力を読む。
4. 個別の操作へ切り替え、各コマンドと出力の対応を確認する。

コマンドだけで確認する場合は、リポジトリのルートで次を実行します。

```bat
rtk node category\StudyBase\scripts\base06-git-practice.mjs all-states
```

## 画面で選べる操作

| 操作 | 確認する内容 |
|---|---|
| 変更前の状態を確認 | `git status --short`に何も表示されない状態 |
| 未ステージの差分を確認 | 作業フォルダだけにある変更と`git diff` |
| ステージ済みの差分を確認 | コミット候補と`git diff --staged` |
| コミットと履歴を確認 | コミット後の空の状態と`git log` |
| 除外ファイルを確認 | `.gitignore`に一致するファイルが変更一覧へ出ない状態 |

## 状態の見方

```text
作業フォルダの変更
  ↓ git add
ステージ上のコミット候補
  ↓ git commit
履歴として確定したコミット
```

`git diff`は作業フォルダとステージの差を表示します。`git diff --staged`はステージと最新コミットの差を表示します。コミット前には、`git status`と`git diff --staged`の両方で対象を確認します。

## 安全な実行範囲

スクリプトはOSの一時フォルダだけに練習用リポジトリを作り、確認後に削除します。外部リポジトリへの接続、push、既存ブランチの変更は行いません。
