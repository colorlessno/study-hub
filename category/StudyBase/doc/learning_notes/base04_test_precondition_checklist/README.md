# base04 テスト成立条件チェック

テストを実行する前に、環境、データ、権限、手順、期待結果、判定者が揃っているか確認します。

## このテーマでできるようになること

- テスト対象と環境の成立条件を分けて記録できる
- アカウント、権限、テストデータの準備状態を記録できる
- 期待結果、合否基準、中止条件、証拠の保存先、判定者を明記できる
- 確認済み、不足、保留、未確認から開始可否を判断できる
- テスト失敗と、条件不足で開始できない状態を区別できる
- 3種類の文書を画面で確認し、Markdownとして保存できる

## 最初に取り組むこと

1. 「固定シナリオを読み込む」を押し、テスト対象と環境の状態を確認する。
2. アカウントとテストデータの不足・保留を確認する。
3. 期待結果、合否基準、中止条件、証拠の保存先、判定者を確認する。
4. 現在の判定が「開始不可」になる理由を確認する。
5. 入力内容を保存し、3種類のプレビューを切り替える。
6. 表示中の文書をダウンロードし、入力内容が反映されていることを確認する。

## 画面で作成する文書

- テスト成立条件チェックリスト
- テスト環境確認表
- テストデータ確認表

入力内容はブラウザ内に保存されます。実在する顧客名、個人情報、秘密情報は入力しないでください。
