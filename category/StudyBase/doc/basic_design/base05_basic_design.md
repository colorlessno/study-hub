# base05 RACI・責任分担 基本設計

## 画面の役割

案件の関係者と作業分担を入力し、RACI、判断待ち、エスカレーションの整合性を確認して3種類の文書へ変換する静的Web画面とする。

## 画面の流れ

| 手順 | 画面で扱う内容 |
|---|---|
| 対象・関係者 | 対象案件、整理する範囲、関係者の役割 |
| 作業別RACI | 最大4件の作業、R、A、C、I、備考 |
| 判断待ち・依頼 | 最大2件の判断待ち、最大2件のエスカレーション |
| 確認・保存 | 件数、整合性エラー、保存、出力 |

画面上部の4つの手順ボタンと、画面下部の「前の手順」「次の手順」で移動する。

## 主な操作

| 操作 | 結果 |
|---|---|
| 固定シナリオを読み込む | 既存システム改修の関係者、作業、判断待ち、エスカレーションを設定する |
| 整合性を確認 | 必須項目、役割の単一指定、関係者一覧との一致を確認する |
| ブラウザ内に保存 | 整合性確認後に入力値をローカルストレージへ保存する |
| 出力文書を切り替える | 3種類のMarkdownプレビューを切り替える |
| 表示中の文書をダウンロード | 選択中の文書をUTF-8のMarkdownとして保存する |
| 保存内容をクリア | 保存値と入力欄を消去し、最初の手順へ戻る |

## 出力文書

| 文書 | 内容 |
|---|---|
| RACI表 | 対象、関係者、作業別のR、A、C、I、備考 |
| 判断待ち事項一覧 | 内容、決定者、期限、未決時の影響、状態 |
| エスカレーションメモ | 決められない事項、理由、影響、依頼先、期限、状態 |

## 表示と保存の方針

- 画面は単一ページ内の4手順に分割し、一度に全入力欄を表示しない。
- 入力はプレーンテキストとして扱い、HTMLを実行しない。
- ローカルストレージのキーはテーマ専用とし、他テーマの保存値と混在させない。
- 外部通信は行わない。
