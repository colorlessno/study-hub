# base03 見積り根拠表 基本設計

## 画面の役割

見積りケースを入力し、範囲と前提、作業別の工数と根拠、リスク、再見積り条件を対応付けて3種類の文書へ変換する静的Web画面とする。

## 画面の流れ

| 手順 | 画面で扱う内容 |
|---|---|
| 範囲・前提 | 依頼内容、見積り対象、対象外、前提、見積り日 |
| 作業分解 | 4件分の工程、作業内容、成果物、工数、根拠 |
| リスク | 2件分のリスク、発生条件、影響、対策、見積りへの影響 |
| 合計・保存 | 合計工数、再見積り条件、補足、保存、出力 |

画面上部の4つの手順ボタンと、画面下部の「前の手順」「次の手順」で移動する。

## 主な操作

| 操作 | 結果 |
|---|---|
| 固定シナリオを読み込む | 受注照会画面の検索条件追加を各入力欄へ設定する |
| 工数を入力する | 作業別工数から合計人日を再計算する |
| ブラウザ内に保存 | 必須項目と使用中の行を確認し、入力値をローカルストレージへ保存する |
| 出力文書を切り替える | 3種類のMarkdownプレビューを切り替える |
| 表示中の文書をダウンロード | 選択中の文書をUTF-8のMarkdownとして保存する |
| 保存内容をクリア | 保存値と入力欄を消去し、最初の手順へ戻る |

## 出力文書

| 文書 | 内容 |
|---|---|
| 見積り根拠表 | 依頼、対象範囲、対象外、前提、合計、見積り日、再見積り条件、補足 |
| 作業分解表 | 作業ID、工程、作業内容、成果物、工数、根拠、合計 |
| リスク一覧 | リスクID、リスク、発生条件、影響、対策、見積りへの影響 |

## 表示と保存の方針

- 画面は単一ページ内の4手順に分割し、一度に全入力欄を表示しない。
- 入力はプレーンテキストとして扱い、HTMLを実行しない。
- ローカルストレージのキーはテーマ専用とし、他テーマの保存値と混在させない。
- 外部通信は行わない。
