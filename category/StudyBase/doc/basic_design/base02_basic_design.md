# base02 情報不足時の暫定成果物 基本設計

## 画面の役割

情報不足ケースを入力し、事実、仮定、未確定事項、利用条件を混同せずに4種類の文書へ変換する静的Web画面とする。

## 画面の流れ

| 手順 | 画面で扱う内容 |
|---|---|
| 情報源 | 依頼、入手済み情報、不足情報、情報源、確認日 |
| 対象範囲 | 目的、対象範囲、書ける範囲、書けない範囲、暫定内容 |
| 仮定・未確定 | 仮定の根拠と影響、未確定事項の確認方法 |
| 限界・保存 | 利用条件、限界、レビュー観点、保存、出力 |

画面上部の4つの手順ボタンと、画面下部の「前の手順」「次の手順」で移動する。

## 主な操作

| 操作 | 結果 |
|---|---|
| 固定シナリオを読み込む | 受注照会画面の情報不足ケースを各入力欄へ設定する |
| ブラウザ内に保存 | 必須項目を確認し、入力値をローカルストレージへ保存する |
| 出力文書を切り替える | 4種類のMarkdownプレビューを切り替える |
| 表示中の文書をダウンロード | 選択中の文書をUTF-8のMarkdownとして保存する |
| 保存内容をクリア | 保存値と入力欄を消去し、最初の手順へ戻る |

## 出力文書

| 文書 | 内容 |
|---|---|
| 暫定成果物 | 依頼、情報源、書ける範囲、書けない範囲、暫定内容、確認待ち |
| 前提・仮定一覧 | 仮定、根拠、影響、確認先、状態 |
| 未確定事項一覧 | 不明点、確認内容、確認先、期限、未解決時の影響 |
| 成果物限界メモ | 限界、利用可能範囲、利用禁止範囲、レビュー観点 |

## 表示と保存の方針

- 画面は単一ページ内の4手順に分割し、一度に全入力欄を表示しない。
- 入力はプレーンテキストとして扱い、HTMLを実行しない。
- ローカルストレージのキーはテーマ専用とし、他テーマの保存値と混在させない。
- 外部通信は行わない。
