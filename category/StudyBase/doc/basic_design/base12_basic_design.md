# base12 基本設計

## 画面の役割

base12は演習を行う画面ではなく、StudyBaseからStudyArchitectureのarch01へ移動するための案内画面です。arch01専用の注文登録システムを使う演習、対象システム概要、整理ひな形、学習進捗はarch01で扱います。他のStudyテーマをarch01の起動対象や保存先として使用しません。

## 画面の構成

| 部分 | 内容 |
|---|---|
| 入口の説明 | base12とarch01の役割を区別する |
| 最初に取り組むこと | arch01へ移動して最初に確認する内容を示す |
| base12で確認すること | 重複教材を作らない理由と正規テーマを示す |
| arch01で扱う内容 | 正規テーマの学習範囲を短く示す |
| 移動できないとき | 分野一覧からarch01を探す手順を示す |

## 操作の流れ

1. base12を開き、正規テーマがarch01であることを確認する
2. 「arch01を開く」リンクを選ぶ
3. arch01のテーマ画面で専用システムの概要と整理ひな形を確認する
4. arch01の学習項目を使って学習を進める

## 進捗の扱い

base12のチェック項目は、案内内容と移動経路を確認したことだけを記録します。システム構成を読み解く演習の進捗はarch01へ記録します。base12にarch01と同じ学習項目は置きません。

## 教材の扱い

base12の教材欄には案内文書と、arch01で使用する主要資料への参照を表示します。参照先はすべて既存のarch01ファイルとし、base12側へコピーしません。

## 実行環境

起動処理、API操作、コマンド実行、ファイル保存は行いません。StudyHubの文書表示と画面内リンクだけを使用します。

## 確認観点

- base12が独立したシステム構成演習に見えないか
- arch01へのリンクが分かりやすいか
- base12とarch01の進捗の記録先を区別できるか
- arch01の主要資料を教材欄から確認できるか
