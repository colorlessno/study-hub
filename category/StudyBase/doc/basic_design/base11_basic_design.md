# base11 基本設計

## 画面の役割

この画面は、ポートフォリオそのものを公開する画面ではありません。学習成果物について入力し、説明案を組み立て、その内容を自分で見直すための教材です。

## 画面の構成

| 部分 | 内容 |
|---|---|
| 説明する内容 | 成果物、聞き手、問題、操作、構成、確認結果、証拠、制限、次の改善を入力する |
| 説明案 | 60秒、3分、5分、録画構成を選び、作成結果を表示する |
| 確認すること | 事実と予定を分ける、安全な情報だけを使うなどの注意を表示する |

## 操作の流れ

1. 記入例を読み込むか、自分の成果物について入力する
2. 作成する説明案を選ぶ
3. 未入力があれば不足項目を直す
4. 作成結果を読み、主張と証拠が対応しているか確認する
5. 説明時間を変え、追加される内容を比較する

## 説明案の作成方針

| 種類 | 作成方針 |
|---|---|
| 60秒 | 成果物、主な操作、構成、確認結果、制限を短くつなぐ |
| 3分 | 問題、作ったもの、構成、確認結果、証拠、制限の順に分ける |
| 5分 | 3分版へ設計上の説明、失敗時に示す事実、まとめを加える |
| 録画構成 | 問題、操作、構成、証拠、制限を画面で見せる順番にする |

## データの扱い

入力値は画面上でのみ保持します。保存、外部送信、ブラウザの記憶領域への書き込みは行いません。「入力を消す」を押すかページを閉じると入力値は残りません。

## ファイル構成

```text
src/apps/base11_portfolio_demo_presentation/app/
  index.html            画面の項目
  src/main.js           入力とボタンの制御
  src/presentation.js   検証と説明案の作成
  src/style.css         画面の見た目
```

既存の台本ひな形、証拠の選び方、制限事項の書き方は、StudyHubの教材欄から参照できます。

## 確認観点

- 未入力を見落とさないか
- 3件を超える証拠を説明案へ入れないか
- 実装済みの事実と今後の予定が分かれているか
- 画面幅が狭くても入力欄とボタンを操作できるか
