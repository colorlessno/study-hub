# base07 ブランチ・マージ・競合解消 基本設計

## 画面の役割

テーマ画面は、ブランチ作成から競合解消後の確認までを段階別に実行し、実際のGitコマンドと結果を表示します。READMEと各記録ひな形も同じ画面から参照できます。

## 画面構成

| 区画 | 表示内容 |
|---|---|
| 学習項目 | 段階別の確認内容と進捗 |
| 実行 | ブランチ、競合、解消、再確認を選ぶ操作一覧 |
| 実行結果 | 実行したコマンド、履歴、状態、ファイル内容 |
| 教材 | README、練習原本、記録ひな形、ソース、設計文書 |
| 実行ログ | StudyHubが起動した処理と終了結果 |

## 実行方式

1回の操作ごとに、練習原本をOSの一時フォルダへコピーします。コピー先でGitリポジトリを初期化し、選ばれた段階まで操作した結果を返します。処理終了時は一時フォルダ全体を削除します。

## 選択できる操作

| 操作 | 実行する流れ |
|---|---|
| ブランチを作成 | mainからfeature/aを作り、現在位置と一覧を表示 |
| ブランチ別のコミットを確認 | 両方へ変更をコミットし、分岐した履歴を表示 |
| 競合を発生 | 分岐したブランチをマージし、競合状態とマーカーを表示 |
| 競合を解消 | 両方を統合してステージし、差分と解消コミットを表示 |
| 解消後を確認 | 最終ファイル、変更のない状態、コミット履歴を表示 |
| すべての手順を確認 | 分岐、競合、解消、再確認を一つの流れで表示 |

## データとファイル

| 種別 | 内容 |
|---|---|
| 練習原本 | READMEとDecision行を持つテキスト |
| 一時データ | mainとfeature/a、分岐コミット、競合状態、解消コミット |
| 表示資料 | ブランチ操作、競合再現、競合解消の記録ひな形 |

## エラー時の扱い

競合を発生させる`git merge`の失敗は期待する結果として扱います。それ以外のGitコマンドが失敗した場合は、コマンド名、終了コード、標準出力、標準エラーを表示します。一時フォルダは成功・失敗にかかわらず削除します。

## 安全性

ファイル操作の対象は、実行時に作成した一時フォルダ配下へ限定します。Git設定は練習用リポジトリのローカル設定だけに書き込み、リモート操作は行いません。
