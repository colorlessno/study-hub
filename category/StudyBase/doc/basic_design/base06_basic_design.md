# base06 Git基本操作 基本設計

## 画面の役割

テーマ画面は、Gitの状態ごとに用意した操作を選び、実際のコマンド結果を表示します。READMEと関連ファイルも同じ画面から参照できます。

## 画面構成

| 区画 | 表示内容 |
|---|---|
| 学習項目 | 状態別の確認内容と進捗 |
| 実行 | Git状態を選ぶ操作一覧と実行ボタン |
| 実行結果 | 実行したコマンドと出力 |
| 教材 | README、練習原本、記録ひな形、ソース、設計文書 |
| 実行ログ | StudyHubが起動した処理と終了結果 |

## 実行方式

1回の操作ごとに、練習原本をOSの一時フォルダへコピーします。コピー先で`git init`と初回コミットを行い、選ばれた状態まで操作した結果を返します。処理終了時は一時フォルダ全体を削除します。

## 選択できる操作

| 操作 | 実行する流れ |
|---|---|
| 変更前の状態を確認 | 初回コミット後に`git status --short`を実行 |
| 未ステージの差分を確認 | ファイル変更後に`status`と`diff`を実行 |
| ステージ済みの差分を確認 | ファイル変更と`add`後に2種類の`diff`を実行 |
| コミットと履歴を確認 | 変更をコミットし、`status`と`log`を実行 |
| 除外ファイルを確認 | ログを作成し、`check-ignore`と`status`を実行 |
| すべての状態を順番に確認 | 1つの一時リポジトリ内で各状態を順番に作る |

## データとファイル

| 種別 | 内容 |
|---|---|
| 練習原本 | README、変更対象テキスト、`.gitignore`、除外対象ログ |
| 一時データ | 初期化したGitリポジトリ、変更内容、コミット履歴 |
| 表示資料 | コマンド記録ひな形、差分読解メモ、失敗例 |

## エラー時の扱い

Gitコマンドが失敗した場合は、コマンド名、終了コード、標準出力、標準エラーを表示します。一時フォルダは成功・失敗にかかわらず削除します。

## 安全性

ファイル操作の対象は、実行時に作成した一時フォルダ配下へ限定します。Git設定は練習用リポジトリのローカル設定だけに書き込みます。
