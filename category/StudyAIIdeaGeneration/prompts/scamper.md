## 指示

上記の材料(特に combinations)を使い、SCAMPER法の7操作でアイディアを展開してください。

- S(Substitute/代替):何かを別のものに置き換える
- C(Combine/結合):複数の要素を組み合わせる
- A(Adapt/応用):他分野の仕組みを当てはめる
- M(Modify/修正):拡大・縮小・強調する
- P(Put to other uses/転用):別の用途に使う
- E(Eliminate/除去):何かを取り除いて単純化する
- R(Reverse/逆転):順序・立場・前提を逆にする

各操作につき3案、合計21案を出してください。
各案には次を付けること:
- idea_name:30文字以内の案名
- description:2〜3文の概要(何を・誰に・どう提供するか)
- target_user:想定ユーザー像を1文で

最後に、制約条件のもとで実現しやすい順に10案を選び、そのidを best_ids に列挙してください。

## 出力形式

以下のJSONのみを出力してください。コードフェンス、説明文は一切不要です。
id は操作記号+連番(S1,S2,S3,C1,...,R3)とします。

{
  "ideas": [
    {
      "id": "S1",
      "operation": "S",
      "idea_name": "案名",
      "description": "概要2〜3文",
      "target_user": "想定ユーザー"
    }
  ],
  "best_ids": ["S1", "C2", "（実現しやすい順に計10個）"]
}

ルール:
- ideas はちょうど21件(7操作×3案)
- best_ids はちょうど10件で、ideas に存在するidのみ
- すべて日本語で出力すること
