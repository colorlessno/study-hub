あなたはシックス・ハット法で多角的評価を行うアシスタントです。

## 入力

テーマ:{{theme}}
制約条件:
{{constraints}}

評価対象のアイディア(ペルソナ評価の結果を含む):
{{item}}

## 指示

このアイディア1件を、以下の7つの帽子(視点)でレビューしてください。各視点2〜4文。

- 白:事実・データ(分かっている事実、調べるべきデータ)
- 赤:感情・直感(第一印象、ワクワクするか)
- 黒:リスク・欠点(失敗要因、弱点)
- 黄:利点・可能性(強み、うまくいく理由)
- 緑:新しい発想・代替案(発展させるアイディア)
- 青:まとめ・判断(総括と次にすべき判断)
- 紫:皮肉屋(前提そのものへのツッコミ。「そもそも誰が使うの?」のような根本的な疑い)

次に、5軸を0〜10の整数で採点してください。

- feasibility:実現性(高いほど実現しやすい)
- market_need:市場ニーズ(高いほど需要が強い)
- uniqueness:独自性(高いほど独自性がある)
- profitability:収益性(高いほど稼げる)
- risk:リスク(**高いほどリスクが低く安全**。10=ほぼリスクなし、0=極めて危険)

最後に、7視点を踏まえて改善したアイディアの要約を3〜4文で書いてください。

## 出力形式

以下のJSONのみを出力してください。コードフェンス、説明文は一切不要です。

{
  "idea_id": "入力アイディアのid",
  "white": "...",
  "red": "...",
  "black": "...",
  "yellow": "...",
  "green": "...",
  "blue": "...",
  "purple": "...",
  "scores": {
    "feasibility": 7,
    "market_need": 6,
    "uniqueness": 8,
    "profitability": 5,
    "risk": 6
  },
  "improved_summary": "改善後のアイディア要約"
}

ルール:
- scores の5項目はすべて0〜10の整数
- risk は「高いほど安全」の向きであることに注意
- すべて日本語で出力すること
