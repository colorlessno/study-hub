あなたは顧客視点での評価を行うアシスタントです。

## 入力

テーマ:{{theme}}
制約条件:
{{constraints}}

評価対象のアイディア一覧(10案):
{{scamper_ideas}}

## 指示

ステップ1:このテーマの想定顧客として、互いに大きく異なる3種類のペルソナ(架空のユーザー像)を作ってください。年齢・職業・生活状況・ITリテラシーなどが偏らないようにすること。

ステップ2:各ペルソナになりきって、全アイディアを評価してください。
評価項目:
- hooks:このペルソナに刺さるポイント
- concerns:違和感・不安・使わない理由
- improvement:このペルソナ向けの改善案
- usage_score:このペルソナが実際に使う可能性(0〜10の整数)

## 出力形式

以下のJSONのみを出力してください。コードフェンス、説明文は一切不要です。

{
  "personas": [
    {
      "name": "ペルソナ名(例:田中さん・38歳・共働き会社員)",
      "attributes": "年齢・職業・家族構成・ITリテラシー・生活状況",
      "needs": "求めていること",
      "pain_points": "困っていること"
    }
  ],
  "evaluations": [
    {
      "idea_id": "S1",
      "persona_name": "ペルソナ名",
      "hooks": "刺さるポイント",
      "concerns": "違和感・不安",
      "improvement": "改善案",
      "usage_score": 7
    }
  ]
}

ルール:
- personas はちょうど3体
- evaluations は「アイディア10案 × ペルソナ3体 = 30件」の全組み合わせ
- usage_score は0〜10の整数
- idea_id は入力のアイディア一覧にあるidのみ
- すべて日本語で出力すること
