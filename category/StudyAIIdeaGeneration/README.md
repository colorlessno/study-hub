# AI発想法の比較演習

AI を使ったアイデア出し（発想支援）ワークフローを設計・検証するための個人学習用プロジェクトです。入力、発想法、出力構造、評価方法を分けて観察します。

## このテーマでできるようになること

- 入力項目、差し込み箇所、指示文の必須項目、確認処理の構成を説明できる
- LM Studioの接続先と、読み込み済みのモデルを確認できる
- 同じ入力で制約を変更し、発想内容と上位案の違いを比較できる
- 5つの発想法を順番に実行し、JSON形式、生成件数、所要時間、トークン数を確認できる

## 最初に取り組むこと

最初はLM Studioへ接続せず、入力JSONと5つの指示文の構造を確認します。

```cmd
cd category\StudyAIIdeaGeneration
python verify\verify_prompts.py --check-only
python -m unittest discover -s verify -p "test_*.py"
```

次に[`exercise/README.md`](exercise/README.md)を開き、基準入力と条件変更後の入力で結果がどう変わるか予想します。LM Studioを利用できる場合は、ローカルサーバーへの接続だけを先に確認してから実際の生成比較へ進みます。

## 学習経路

| 段階 | AI接続 | 確認すること |
|------|--------|--------------|
| 構造確認 | 不要 | 入力項目、差し込み箇所、指示文の必須項目、確認処理 |
| 接続確認 | LM Studio | ローカルサーバーのURL、読み込み済みモデル。生成処理は行わない |
| 2入力比較 | LM Studio | 制約変更が発想内容と上位案へ与える影響 |
| 全工程検証 | LM Studio | 5手法の連結、JSON形式、件数、所要時間、トークン数 |

## 構成

```text
category/StudyAIIdeaGeneration/
  doc/        ワークフローアプリの設計まとめ
  prompts/    発想法プロンプト（mindmap / persona / scamper / six_hats / reverse_plan 等）
  exercise/   基準入力・変更入力・比較表を使う反復演習
  verify/     プロンプト検証用スクリプトと入力例
```

## 内容

- AI アイデア出しワークフローの設計（`doc/ai_ideation_workflow_app_design_v2.md` ほか）
- 複数の発想フレームワーク（マインドマップ、ペルソナ、SCAMPER、シックスハット 等）のプロンプト
- プロンプトの挙動を確認する検証スクリプト
- API接続なしで繰り返し実行できる構造確認と単体テスト
